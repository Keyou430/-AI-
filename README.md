# 视频二创 AI 助手

面向企业新媒体团队的 Windows 桌面工具：解析抖音、小红书视频，结合业务关键词与本地知识库生成分镜和口播脚本。

## 通用版 1.0.6

只交付一份安装包：release/video-remix-universal-setup-1.0.6.exe。管理员与员工安装同一版本，登录后按服务器角色显示权限；管理员可新增账号、停用账号和重置密码。生产安装包固定使用远程账号服务，不提供本机管理员初始化。

服务器只负责账号鉴权、权限管理、会话撤销与审计。知识库、关键词、接口地址、模型和 API Key 均按设备保存在本机，业务由本机直接访问供应商，授权服务器不接收密钥、提示词或业务结果。

## 功能

- 粘贴抖音／小红书链接，提取发布文案与视频口播，人工核对修改后再二创；支持流式生成和多轮优化。
- 原始发布文案、原始口播与人工修改稿分别保存，历史可对照，提取草稿跨重启保留。
- LinkDigest 支持异步视频提取、图片 OCR 与描述、覆盖凭据和积分提示，图文素材可填入编辑区。
- PDF、DOCX、TXT、MD、CSV 知识库导入、启停和删除；业务关键词管理。
- SQLite 历史记录、筛选、编辑、版本回退和导出。
- 统一账号登录、管理员账号管理、停权与断网锁定。
- UTF-8 JSONL 运行日志，关联操作与异常，排除密码、密钥和正文。

Word 导出为 HTML 兼容的 .doc 文件，并非原生 .docx。同一设备上的不同账号共享本机业务数据。

## 保存与接口设置

新设备的知识库、关键词和接口配置为空。原设备的导入、增删、修改和启停持续保存，重启或退出登录不会清除。

登录后在“系统设置 → API 密钥与模型配置”填写 HTTPS 接口地址、模型和 API Key，点击“保存本设备接口配置”。密钥使用操作系统安全存储加密保存到应用数据目录的 providers.encrypted，不写入 localStorage，不在界面回显；显示“已配置”表示已经保存。填写新密钥覆盖旧值，密钥框留空保留已有值。管理员和员工均可配置本机接口。

默认启用仿真模式。配置真实接口后关闭仿真：

1. “AI 二创”点击“使用 DeepSeek 配置”，填入自己的 DeepSeek Key；按钮填充官方 Base URL 和当前官方模型 ID `deepseek-flash`，仍可修改为其他 OpenAI 兼容服务。
2. “内容提取”可选择“LinkDigest（文案＋口播＋图文 OCR）”，填写其 Key，设置单次积分上限（默认 5），程序自动处理异步任务。也可继续使用“姚安 AIGC（链接解析＋口播转写）”或原有自定义接口；新设备不自动选定厂商或填入 Key。
3. 保存后关闭仿真模式，在工作台粘贴完整分享链接，点击“提取文案与口播”。发布文案与口播分别显示；修改口播后点击下方生成按钮。二创和多轮优化不会重复提取视频。
4. 提取不自动重新提交；再次点击提取可能产生费用。LinkDigest 的 202 任务仅通过 GET 查询原任务，最长等待约 150 秒。鉴权、预算不足、限流、平台拒绝、空结果等分别提示；退出或停权取消本机等待，不代表厂商任务取消或退款。
5. “自定义接口（高级配置）”保留完整 HTTPS 地址、GET／POST JSON、四种鉴权、请求及响应字段路径、超时设置。原有通用配置继续兼容。更换提取厂商时须填写新厂商的 Key，避免误发旧 Key；同一厂商密钥框留空保留原值。
6. LinkDigest 详情单独展示图片 OCR、图片描述、屏幕文字、AI 要点、覆盖凭据及积分消耗；图片按返回顺序保留空项，不独立保证原帖顺序。可点击“将正文／OCR 填入编辑区”，核对修改后再二创，不把摘要或图片描述冒充口播。姚安仍仅提供正文与口播。
7. 厂商适配均依据公开协议与测试响应验收，尚未使用真实 Key 验证商业接口效果；抖音可能被厂商／平台拒绝，不能保证完整读取。详细约定见 docs/链接提取与人工二创.md 和 docs/LinkDigest接入与验收.md。

长期保存以本机应用数据未删除、当前系统用户仍可解密为前提；不自动跨设备同步。旧版保存在服务器的配置不会自动下发，升级后需在本机重新填写。本次线上旧配置已检查无密钥并移入备份。

## 鉴权与停权

正式地址：https://114.132.186.95。每次业务操作检查账号，空闲时每 30 秒检查；任务执行期间每秒检查一次，发现停用、密码重置、会话到期或授权服务不可达时取消请求并锁定。网络检查有超时，停权生效时间包含检查间隔及网络耗时。退出登录立即取消本机任务。

客户端本机直连供应商，因此已导出的资料、已复制的 Key 或用户自行修改程序的行为不受账号服务器控制。系统加密保护磁盘静态数据，不能保证防止当前系统用户提取 Key；需要保护公司的供应商 Key 时，应使用供应商独立额度和撤销策略。

## 技术栈与验证

Electron、React 18、TypeScript、Vite、Tailwind CSS、Radix UI、Zustand；SQLite 优先 better-sqlite3，原生模块不可用时使用 sql.js；OpenAI SDK、pdf-parse、mammoth。

需要 Node.js 22.12+，Windows PowerShell：

~~~powershell
npm ci
npm run typecheck
npm test
npm run build:auth
npm run build
npm run smoke:desktop
npm run smoke:persistence
npm run dist:win
~~~

只保留 dist:win / pack:win 通用版构建入口。默认使用正式鉴权地址，也可通过 REMIX_AUTH_URL 指定有效 HTTPS 根地址。源码中的本机账号模式仅用于隔离开发测试，不进入正式包；打包会替换远程入口并排除本机授权实现。构建通用包后，如需再运行本机隔离验收，先执行 npm run build 恢复开发编译产物。不要分发已初始化的应用数据目录。

正式包联网持久化验收：

~~~powershell
$env:REMIX_SMOKE_ADMIN_FILE = '管理员初始凭据文件的绝对路径'
node scripts/desktopPersistenceSmoke.cjs --remote
~~~

验收使用临时应用数据和隐藏窗口。真实鉴权连接线上；供应商请求使用验收响应，验证本机保存的 Key、地址和模型被直接使用，不产生商业调用费用。尚未完成真实商业供应商联调、代码签名和实体员工设备安装卸载验收。

日志入口为“系统设置 → 打开运行日志”，位置为应用数据目录的 logs。按日期和大小轮转，保留 14 天且最多 20 个文件；重要记录需另行备份。

部署和备份说明见 docs/集中授权部署.md，任务与历史验收记录见 docs/TASKS.md。旧员工版安全审查报告为历史架构记录，当前通用版以本文和部署说明为准。

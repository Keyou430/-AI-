# 视频二创 AI 助手

面向新媒体团队的 Windows 桌面工具，支持视频内容提取与脚本二创、小红书图文策划与生图，以及结合行业标签的热点推荐。当前版本：**2.0.10**。

## 下载与安装

在本仓库的 [Releases](https://github.com/Keyou430/-AI-/releases) 下载 `video-remix-universal-setup-2.0.10.exe`，通过同页 SHA-256 文件校验后安装。安装包为 Windows x64 远程授权通用版，尚未进行代码签名。

1. 首次安装时填写管理员提供的授权服务器 HTTPS 根地址。公开安装包不内置服务器地址；安装器验证接口后保存本机绑定。
2. 启动后使用管理员分配的账号登录，在“系统设置 → API 接口配置”配置文字模型、内容提取与图片模型。
3. 已有有效绑定的覆盖升级保留绑定和本机接口设置。旧版尚无安装绑定时，升级需要填写服务器地址，不能静默跳过。
4. 主动卸载会清除授权绑定和本机 API 设置；业务数据库、素材和知识库保留。更换服务器需卸载重装，并重新填写接口密钥。

## 主要功能

| 模块 | 功能 |
| --- | --- |
| 视频二创 | 提取视频文字与画面信息，结合行业标签、业务简介及启用的知识库生成和优化脚本。 |
| 小红书图文 | 读取原帖或手动录入内容，先分析原内容与目标行业的关联点，再生成标题、正文、话题与分页策划；确认后连续生图。 |
| 图片编辑 | 参考图、场景图、单图优化、全局差异重生成、成功版本恢复，以及图片与发布文案导出。 |
| 行业热点 | 聚合平台话题，展示来源更新时间，按当前行业预设推荐，支持转入视频二创和图文策划。 |
| 本机资料 | 历史记录、知识库、存储目录与接口设置；历史条数按实际保存的记录统计。 |
| 账号管理 | 远程登录与状态校验，管理员创建、停用、删除账号和重置密码。 |

图文逐图编辑优先显示当前页、图片增删、“图片内文字”和“画面要求”；目标行业、行业标签及说明位于编辑内容之后。“策划说明与核对事项”位于最底部，默认收起。热点页“全部”位于行业下拉框左侧，切换预设后显示当前选择并刷新数据；话题操作入口保持同一行，平台占比图与图例支持平台筛选，来源详情可展开查看。

## 数据源与更新方式

热点接入使用 UApi 聚合热榜。界面包含抖音、微博、知乎、小红书、今日头条、视频号六个平台入口；视频号当前显示“数据源待接入”，没有可用热榜数据。小红书沿用现有聚合源，尚未接入经验证可持续更新的免费替代服务。

热点缓存有效期为 20 分钟，页面加载会根据缓存和行业上下文判断是否重新请求，手动刷新可强制请求上游。超过 24 小时未更新的榜单显示过期提示，并排除行业推荐；刷新失败时保留上次成功结果并提示状态。缓存期限不代表上游承诺的更新频率。

内容提取支持 LinkDigest、姚安和自定义接口；图片模型支持 Agnes、Seedream、GLM 文字生图及 Sub2API 异步生图。具体能力以系统设置中的预设和实际服务协议为准。模型、提取与生图请求可能产生服务商费用。

## 本机数据与接口配置

API 密钥由主进程使用系统安全存储加密保存，不写入前端 localStorage，也不在界面回显。管理员与员工均可配置本机接口。主动退出或同设备换号保留本机资料；管理员停用账号时清除设备 API 配置，保留业务历史和素材。

账号服务只负责授权，客户端直接请求所配置的模型及内容服务。导出后由使用者自行发布，不自动登录内容平台。生产账号、密钥、证书、实际部署地址、压测结果及内部交付备份不属于公开仓库内容。

## 开发与构建

需要 Node.js **22.12 或更高版本**，Windows x64 构建环境。

```powershell
npm ci
npm run typecheck
npm test
npm run build
```

Windows 远程授权安装包：

```powershell
npm run dist:win
```

安装包输出到 `release/`，仅携带安装绑定模式，授权地址由使用者在安装时填写。构建不需要生产授权地址或凭证。

授权服务：

```powershell
npm run build:auth
npm run start:auth
```

启动前根据 [授权服务部署说明](docs/集中授权部署.md) 配置自己的运行环境。不要把真实环境变量、账号数据库和证书加入版本控制。

# 视频二创 AI 助手

面向企业新媒体团队的 Windows 桌面工具：解析抖音视频、小红书视频及图文，结合业务关键词与本地知识库生成视频脚本，或生成小红书图文图片及配套文案。

1.0.26 配套远程授权服务：管理员停用普通账号后，员工客户端清除本机 API 配置；员工主动退出、同设备换号、普通登录失效及密码重置保留配置。停用不删除历史、知识库与素材，重新启用不恢复已清除的旧密钥。

1.0.26 已通过 254 项源码测试及正式安装包验收：9 项停用清理检查、33 项设置检查、41 项布局检查和 F01–F05 图文回归。供应商调用均使用隔离样本，未操作真实员工数据。

1.0.25 新增 Sub2API（异步生图）预设，支持文字生图、参考图与文字共同生成，以及沿用当前图优化；同一 API Key 提交与轮询，完成后下载保存。设置入口和完整异步流程已包含在本版安装包。

1.0.24 撤回 GLM“参考图＋文字生成”服务，移除自部署预设、自动切换、图生图请求和相关上传入口，仅保留 GLM 官方文字生图。旧图生图配置读取时自动改为官方文字预设并清除旧图片密钥，需重新填写智谱 API Key；其他模块配置、已有素材和历史图片保留。Agnes／Seedream 继续支持参考图。

1.0.25 安装包构建与正式包验收通过：33 项设置检查、41 项布局检查和 F01–F05 回归通过；18 次图片供应商请求均为模拟响应。本轮核对源码哈希后复用上一轮 233 项完整测试通过结果。

1.0.22 授权调整：任务内授权检查每 15 秒一次，空闲仍为 30 秒；临时断联按最近一次真实授权成功起算给予最多 60 秒宽限。当前已提交任务继续等待，下一张实时校验成功后才提交；等待期间可取消，明确停用／失效立即处理。成功图片复用后端归档结果，避免结束校验或重复保存失败造成丢失。

## 功能

- 粘贴抖音／小红书链接，提取发布文案与视频口播，人工核对修改后再二创；支持流式生成和多轮优化。
- 原始发布文案、原始口播与人工修改稿在历史中分别保存，可重新编辑。每次启动工作台的链接、素材与脚本保持空白，设置与历史保留。
- LinkDigest 支持异步视频提取、图片 OCR 与描述、覆盖凭据和积分提示，保留原帖关键词。视频进入原工作台，小红书图文自动进入独立模块；类型无可靠凭据时允许人工指定，不重复提取。
- 小红书图文自动融合启用的知识库，生成文案和分页草案；核对张数、风格及整套比例并确认一次后，由当前图片模型（Agnes／Seedream／GLM／Sub2API，能力限制见系统设置）连同中文整张生图。支持上一图／下一图、单图优化与全局差异重生成、按页绑定实际场景图、有序图片和发布文案导出。
- 图文草案支持当前图前后插入与删除，至少保留一图；旧分页结构入口已移除。自动检查结果写入受限日志，独立核对分页及提示不展示；全部成功页面版本保留，位于本图要求下方，可切回旧版并人工标记图内文字已核对。全局优化先预览影响范围与次数；标题／正文／话题上限尚待团队提供。
- 导出包含有序图片、发布文案和内部核对清单；内部说明不进入发布文案。删除图文历史前展示图片数量与占用，清理全部版本与图片，失败可恢复。
- 图文标题、单行链接与操作按钮同行，长链接不换行。确认前保留文案／逐图／风格／素材，确认后只保留发布文案／素材；发布标题、正文和话题可直接编辑、就近复制并保存，仅改发布文案不生图。重试位于顶部；上一图／下一图固定在图片下方，单页隐藏，多页支持方向键，窄窗口可切换策划编辑／图片预览。
- 工作台与历史详情合并脚本标签、镜头翻页和工具按钮，历史视频以一个导出菜单提供文本／文档；图文历史宽栏采用图片与发布文案并排，图片等比完整显示、用满可用高度且固定不滚动，文字独立滚动。三模块共用列宽及间距，实测结果见 docs/三模块布局与启动状态调整方案-2026-10-29.md。
- 图文与视频共用历史页，可按类型筛选；图片默认跟随数据目录，也可在系统设置中配置独立素材目录，下次启动迁移并保留原目录备份。
- PDF、DOCX、TXT、MD、CSV 知识库导入、启停和删除；业务关键词管理。
- SQLite 历史记录、筛选、编辑、版本回退和导出；删除前确认，复制跟随当前标签。
- 统一账号登录、管理员账号管理、停权撤销与网络异常恢复。
- UTF-8 JSONL 运行日志，关联操作与异常，排除密码、密钥和正文。

Word 导出为 HTML 兼容的 .doc 文件，并非原生 .docx。同一设备上的不同账号共享本机业务数据。

## 保存与接口设置

新设备的知识库、关键词和接口配置为空。原设备的导入、增删、修改和启停持续保存，重启或退出登录不会清除。

登录后在“系统设置 → API 接口配置”填写 HTTPS 接口地址、模型和 API Key，点击“保存本设备接口配置”。密钥使用操作系统安全存储加密保存到应用数据目录的 providers.encrypted，不写入 localStorage，不在界面回显；显示“已配置”表示已经保存。填写新密钥覆盖旧值，同一服务商密钥框留空保留已有值；更换服务商须填写新密钥。三张卡片分别保存，测试使用当前表单且不自动保存。管理员和员工均可配置本机接口。

应用仅调用真实接口，不提供仿真模式或示例结果。使用前请完成本机接口配置：

1. “智能二创”点击“使用 DeepSeek 配置”，填入自己的 DeepSeek Key；按钮填充官方 Base URL 和当前官方模型 ID `deepseek-flash`，仍可修改为其他 OpenAI 兼容服务。
2. “内容提取”提供“使用 LinkDigest 配置”“使用姚安配置”和自定义接口；填写对应 Key，基础地址可编辑。LinkDigest 单次积分上限默认 5，自动处理异步任务；自定义接口保留请求方式、鉴权、字段映射及超时配置。
3. “图片生成”提供“使用 Agnes 配置”“使用 Seedream 配置”“使用 GLM 配置”“使用 Sub2API（异步生图） 配置”；按厂商填写完整地址、模型和 Key。Seedream 默认采用 5.0 pro，逐页生成 2K 图片，最多 10 张参考图；Agnes 沿用原有生图请求。GLM 仅保留官方文字生图，整页提示词超过 1000 字符会明确提示；参考图上传和上一版图片参考入口关闭，已有素材可查看、移除，旧绑定可取消。使用参考图请切换 Agnes／Seedream。Sub2API 预设按[异步生图接入说明](docs/Sub2API异步生图预设.md)配置，支持文字生图、参考图与文字共同生成，以及上一版图片优化；用同一 Key 提交和轮询，完成后下载落盘。保留智能二创的模型连接测试，内容提取和图片测试按钮已移除。
4. 保存后在原工作台或“小红书图文”粘贴完整分享链接并提取。视频在原工作台核对后生成脚本；小红书图文自动跳转并策划，核对／修改文案、张数、风格与整套比例，确认一次后连续生图。自动获取不到原图或比例时可补传原帖参考图，并在同一次确认前调整比例。
5. 图文的“图片优化”仅更新指定页；“全局优化”只重生成受影响页面。仅修改发布标题、正文或话题不影响图内内容时不生图。首次确认可选上传实际场景图作为整套参考，首轮完成后可按页绑定素材，要求保留关键外观。导出素材包后自行发布，不自动登录小红书。
6. 提取不自动重新提交；再次点击提取可能产生费用。LinkDigest 的 202 任务仅通过 GET 查询原任务，最长等待约 150 秒。鉴权、预算不足、限流、平台拒绝、空结果等分别提示；退出或停权取消本机等待，不代表厂商任务取消或退款。
7. “自定义接口（高级配置）”保留完整 HTTPS 地址、GET／POST JSON、四种鉴权、请求及响应字段路径、超时设置。原有通用配置继续兼容。更换提取厂商时须填写新厂商的 Key，避免误发旧 Key；同一厂商密钥框留空保留原值。
8. LinkDigest 详情单独展示图片 OCR、图片描述、屏幕文字、AI 要点、覆盖凭据及积分消耗；图片按返回顺序保留空项，不独立保证原帖顺序。可用图文自动填入正文与图片文字，关键词取自原帖标签；也可重新填入原文，核对修改后再二创，不把摘要或图片描述冒充原文。姚安仍仅提供正文与口播。
9. 厂商适配依据公开协议与测试响应验收，并对已保存的真实 LinkDigest 图文响应进行回放核验；这不代表所有商业链接的成功率与准确度均已达标；抖音可能被厂商／平台拒绝，不能保证完整读取。详细约定见 docs/链接提取与人工二创.md 和 docs/LinkDigest接入与验收.md。

长期保存以本机应用数据未删除、当前系统用户仍可解密为前提；不自动跨设备同步。旧版保存在服务器的配置不会自动下发，升级后需在本机重新填写。本次线上旧配置已检查无密钥并移入备份。

## 鉴权与停权

正式地址：https://114.132.186.95。当前源码在新任务提交前实时检查账号，任务期间每 15 秒检查一次，空闲每 30 秒检查一次，窗口获得焦点时也检查。同一会话只合并在途身份查询，完成后不复用缓存作为新任务授权。只读身份查询发生临时连接失败、超时或响应异常时，等待 250 ms 后重试一次，每次请求上限 5 秒。已提交任务的临时 AUTH_UNAVAILABLE 按最近一次服务端授权成功起算给予最多 60 秒宽限；失败不续期，期限到达即停止。后续图文任务可在剩余宽限内等待恢复，但校验成功前不调用供应商；等待可取消。任务完成后的临时授权故障在宽限内允许返回成功结果，成功图片保留后端归档。明确停用、密码重置或登录失效立即撤销会话并取消任务；登录和账号修改不自动重提。停权发现时间包含检查间隔及网络耗时。退出登录立即取消本机任务和旧会话授权查询。此策略已包含在 1.0.22 安装包中。

客户端本机直连供应商，因此已导出的资料、已复制的 Key 或用户自行修改程序的行为不受账号服务器控制。系统加密保护磁盘静态数据，不能保证防止当前系统用户提取 Key；需要保护公司的供应商 Key 时，应使用供应商独立额度和撤销策略。

## 技术栈与验证

Electron、React 18、TypeScript、Vite、Tailwind CSS v3、Base UI、Radix UI、Motion、Zustand；SQLite 优先 better-sqlite3，原生模块不可用时使用 sql.js；OpenAI SDK、pdf-parse、mammoth。

需要 Node.js 22.12+，Windows PowerShell：

~~~powershell
npm ci
npm run typecheck
npm test
npm run build:auth
npm run build
npm run smoke:desktop
npm run smoke:persistence
npm run dist:win
~~~

只保留 dist:win / pack:win 通用版构建入口。默认使用正式鉴权地址，也可通过 REMIX_AUTH_URL 指定有效 HTTPS 根地址。源码中的本机账号模式仅用于隔离开发测试，不进入正式包；打包会替换远程入口并排除本机授权实现。构建通用包后，如需再运行本机隔离验收，先执行 npm run build 恢复开发编译产物。不要分发已初始化的应用数据目录。

正式包联网持久化验收：

~~~powershell
$env:REMIX_SMOKE_ADMIN_FILE = '管理员初始凭据文件的绝对路径'
node scripts/desktopPersistenceSmoke.cjs --remote
~~~

验收使用临时应用数据和隐藏窗口。真实鉴权连接线上；供应商请求使用验收响应，验证本机保存的 Key、地址和模型被直接使用，不产生商业调用费用。尚未完成真实商业供应商联调、代码签名和实体员工设备安装卸载验收。

日志入口为“系统设置 → 打开运行日志”，位置为应用数据目录的 logs。按日期和大小轮转，保留 14 天且最多 20 个文件；重要记录需另行备份。

部署和备份说明见 docs/集中授权部署.md，任务与历史验收记录见 docs/TASKS.md。旧员工版安全审查报告为历史架构记录，当前通用版以本文和部署说明为准。

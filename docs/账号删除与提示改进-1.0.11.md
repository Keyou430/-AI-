# 账号删除服务更新（1.0.11）

此包供服务器管理员使用，员工电脑仍只需要Windows安装包。

新增 POST /v1/users/delete。要求管理员会话；拒绝删除内置admin与当前账号；成功后撤销目标所有会话，不删除业务历史。请求/日志不记录密码或令牌。

本地代码、编译产物及隔离本地授权服务验收已通过；已于 2026/10/27 09:05:07（北京时间）部署线上 1.0.11。服务已重启，在线用户需要重新登录。

更新步骤：
1. 停止 video-remix-auth，备份 /opt/video-remix-auth 代码与 /var/lib/video-remix-auth 数据目录。
2. 用包内 dist-server 替换服务代码，保留原账号数据、密码文件及有效依赖；依赖未变化时可复用原node_modules。
3. 按 docs/集中授权部署.md 原有流程启动服务，检查健康、登录和管理员删除接口权限。不要通过删除真实用户进行冒烟测试。
4. 失败时停止服务、恢复备份代码后重新启动；保留原数据目录。

新客户端连接未升级服务时，会提示“授权服务尚未支持删除账号，请联系管理员更新服务后重试”，不会误退出当前管理员会话。

客户端变更：密码重置改为居中模态框，输入新密码并确认；删除账号使用独立确认框，默认聚焦取消。新设备不预置历史与知识库，仿真默认关闭；升级仅移除完全未编辑的内置历史示例。错误Toast固定视口顶部，保留字段值并指出配置字段、链接平台或剪贴板权限问题。

验证：90项测试、类型检查、生产构建、桌面冒烟和六阶段持久化回归；打包验收证据以 release/universal-package-acceptance.json 为准。线上 HTTPS 健康、管理员/员工登录、内置管理员保护、员工删除权限、临时账号密码重置与会话撤销、删除后全部会话撤销均已验证。临时验收账号已清理，原有12个账号的凭据、角色、状态等字段与更新前一致（登录时间正常更新）。部署记录见 release/auth-service-deployment-1.0.11.json；备份位于 /var/backups/video-remix-auth/update-1.0.11-20261027T010505Z-PmVfeQFk。未执行NSIS覆盖安装及真实厂商调用。

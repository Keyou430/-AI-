# 产品需求文档（PRD）— 视频二创 AI 助手

产品版本：1.0.27 通用版

更新日期：2026-11-09

状态：按 1.0.27 安装包记录、当前源码与已有验收记录更新；本次仅同步 PRD，未重新执行软件测试。未完成事项见第 8 节。

## 1. 产品定位与范围

面向短视频创作者、企业新媒体运营和品牌团队的 Windows 桌面工具。用户导入抖音／小红书分享链接或手动输入视频素材，核对提取结果，结合公司业务、关键词与本地知识库，生成拍摄脚本、拍摄手法及口播稿；小红书图文使用独立模块生成整套图片与配套发布文案。拍摄和平台发布由用户自行完成。

当前采用“提取 → 人工核对或修改 → 二创 → 多轮优化”的分步流程。旧版 PRD 中并列的“一键提取并二创”入口不属于当前界面。应用仅调用真实接口，不提供仿真模式、示例结果或预置历史记录。

管理员与成员使用同一安装包，登录后按服务端角色展示权限。授权服务负责账号、权限、会话与审计；素材提取和模型生成由客户端直连用户配置的供应商，不通过授权服务转发。

## 2. 核心用户流程

| 步骤 | 用户操作 | 系统行为与完成标准 |
| --- | --- | --- |
| 安装与绑定 | 运行 1.0.27 安装包，在“绑定授权服务器”填写管理员提供的 HTTPS 根地址 | 验证通过并确认后继续安装；地址绑定后不能在软件中修改 |
| 登录与配置 | 使用已有账号登录，在“设置”填写内容背景，分别保存所需接口配置 | 正式包使用远程账号服务；新设备需自行配置，不自动取回其他设备的 Key、知识库或历史 |
| 输入素材 | 粘贴完整分享文案／链接，或直接输入视频素材文字 | 从分享文本识别 URL，校验支持平台并保留小红书分享参数；直接输入文字可跳过提取 |
| 视频提取与核对 | 在“二创工作台”点击“提取文案”，核对“口播文案”和“画面描述” | 仅提取，不自动生成脚本；原始素材与人工稿分开保留 |
| 视频二创与优化 | 在“生成选项”设置时长与运镜，点击“生成二创脚本”；需要时点击“优化脚本” → “发送并优化” | 将当前人工稿、公司背景、分类关键词和启用的知识库发送给模型，流式显示结果；生成不重复提取，优化保存版本 |
| 图文提取与策划 | 在“小红书图文”粘贴链接，点击“提取并继续” | 提取并形成文案与逐图草案；从工作台识别到图文时进入独立图文模块，不重复提取 |
| 图文确认与生成 | 核对“文案”“逐图”“风格”“素材”，选择整套比例，再确认生成图片 | 确认前不调用生图服务；确认一次后生成整套图片，部分失败可只重试未完成图片 |
| 核对与导出 | 视频从“历史记录”导出；图文逐图核对后“保存” → “导出素材包” | 视频导出 TXT 或兼容 Word 的 .doc；图文导出有序图片、发布文案及内部核对文件 |

### 2.1 首次安装与升级规则

- 交付安装包为 `release/video-remix-universal-setup-1.0.27.exe`。首次安装时填写管理员提供的 HTTPS 根地址，不附加业务路径；验证失败时阻止继续，保留重新填写入口。
- 绑定成功前须确认“绑定后无法在软件中修改服务器地址”。断网、停服或绑定文件损坏不开放修改地址的入口。
- 覆盖升级保留已有绑定与本机 API 配置；旧固定地址版本升级沿用构建时兼容地址。
- 主动使用 1.0.27 卸载程序卸载时，清除当前 Windows 用户的服务器绑定与本机 API 配置，保留历史、知识库和业务素材。更换服务器需卸载重装，重新准备配置资料。
- 正式包不提供本机管理员初始化、自助注册或找回密码；登录账号、初始密码及服务器地址由管理员提供。

## 3. 工作台与图文创作

### 3.1 链接输入与错误反馈

- 支持抖音、小红书完整分享文本和链接；剪贴板为空、读取失败、链接无效和平台不支持时，显示具体中文错误及 Toast。
- 链接框内提供可访问的清除按钮，便于重新粘贴。
- 提取或生成期间限制重复提交。提取失败保留明确原因，用户手动决定是否重试，不自动重新付费提取。
- 无链接时允许直接输入素材文案进行二创；编辑内容为空时阻止生成。

### 3.2 提取内容与原稿

| 内容类型 | 编辑区默认内容 | 补充展示 | 处理边界 |
| --- | --- | --- | --- |
| 视频 | 接口实际返回的口播文字 | 发布正文、口播状态、可用的图文与覆盖详情 | 发布正文、OCR 和智能摘要不得冒充原始口播；已知视频缺少或仅返回部分口播时保留准确提示 |
| 小红书图文 | 正文、逐图 OCR／可用 OCR 汇总及画面文字，交给独立图文模块策划 | 素材关键词、逐图详情和原帖素材供核对 | 图文不以返回口播为成功条件；不显示误导性的缺口播提示，不以未知口播时长干扰图文核对 |

图文文字按原始内容组合；有逐图 OCR 时不重复加入 OCR 汇总。图片按接口返回位置编号，空项保留，不独立承诺原帖顺序。智能图片描述和分析要点独立展示，不自动填入原文编辑区。

素材关键词优先使用接口 tags，并从原始正文／图片文字中的话题标签补齐、去重；旧记录没有 tags 时仍可从原文话题补齐。无来源时不编造关键词。素材关键词与公司业务关键词分开处理。

正文、口播、人工稿、逐图 OCR、覆盖信息和费用信息随草稿／历史保留。历史中的原稿对照与复制使用对应的真实素材，图文不展示为空的原始口播。人工修改优先用于二创，保留原始来源供核对。

删除以下两条冗余提示，但保留缺图、转写失败等真实异常：

- “口播已返回，但完整性待核对，请查看提取说明。”
- “厂商注明有未读取内容，可能涉及评论、画面或其他素材；本结果不是整帖完整副本。”

### 3.3 编辑与生成

- Composer 支持自动增高、粘贴／拖入文字、焦点反馈、字数提示及 Ctrl／Command + Enter 提交；中文输入法组合输入期间不触发提交，忙碌期间限制编辑和重复操作。
- 在“生成选项”设置“目标时长（秒）”（6–180 秒）和“指定运镜（可选）”，核对素材后点击“生成二创脚本”。模型提示要求结合公司业务与素材结构，按顺序输出分镜，包含人员动作、运镜／拍摄标准及声音内容。
- 输出要求包含总时长、镜头时序、指定运镜、违禁词与不出现字幕等约束。约束由提示与结果检查辅助实现，不承诺所有模型响应天然合规，用户仍需核对。
- 结果以“拍摄脚本”“拍摄手法”“口播稿”“全文”标签展示；具备来源记录时提供“原稿对照”。拍摄脚本与拍摄手法支持按镜头分页，复制仍按当前标签获取对应完整内容。
- 优化提交当前上下文和修改指令，保存版本快照；版本回退保留历史版本。普通二创创建新的历史记录，优化在当前记录中追加版本。
- 切换记录时隔离生成结果，避免旧请求写入另一条记录。保存失败需明确提示，并保留已生成内容。

### 3.4 小红书图文二创

- 提取后自动结合启用的公司知识库形成草案。确认前保留“文案”“逐图”“风格”“素材”四个分页；“文案”编辑发布标题、配套发布正文和话题，“逐图”编辑图片内文字与画面要求。
- 整套支持 1–30 张。通过“增加一图” → “往前增加”／“往后增加”插入，通过“删除当前图”移除，至少保留一图；切换图片时同步当前编辑内容。
- “整套图片比例”支持 1:1、3:4、4:3、16:9、9:16、2:3、3:2、21:9。核对文字、张数和比例后，点击“确认文案、张数及比例，开始生成 N 张图片”，N 随实际张数变化；确认前不生图，确认后无需逐页再次确认。
- 支持参考图的厂商可通过“补传原帖参考图”“上传实际场景参考图（可选）”补充素材。支持 PNG、JPG／JPEG、WEBP，单张不超过 20 MB，稿件最多 30 个参考素材，并受所选厂商单次限制约束。
- 确认后编辑区只保留“发布文案”“素材”；发布标题、正文和话题可直接编辑，点击“复制文案”复制，点击“保存”持久化。只修改发布文案不重新生成图片。
- 顶部显示进度与“取消任务”；未完成页面显示“继续／重试 N 张未完成图片”。保留成功图片，仅处理失败或内容已更新的页面；取消只停止本机等待，不承诺撤销供应商任务或退款。
- 图片预览提供“上一图”“下一图”和图片选择；单图时隐藏翻页，多图支持方向键。“页面版本”保留成功版本，可切换查看。
- “图片优化”调整当前图片文字与画面，可按能力补传实际场景图或附带上一版图片，点击“优化并重生成本图”仅更新本页。“全局优化”先展示影响页数与原因，涉及重新策划时先“生成优化预览”，核对后“应用全局优化”；只改发布文字时“仅更新文案”。
- 逐页人工勾选“图内文字已核对（重生成或切换版本后清除）”。自动检查不代替人工核对；重生成或切换图片版本后重新检查、重新勾选。
- “导出素材包”在所选目录中新建“小红书图文-…”文件夹，包含顺序编号 PNG、`发布文案.txt` 和 `内部核对.txt`，不是 ZIP。未成功生成的页面会跳过，须核对导出张数；内部核对信息不混入发布文案。软件不自动发布。

## 4. 历史记录与删除保护

- SQLite 保存历史，支持“全部内容”“视频”“图文”分类、平台筛选、检索、详情、重新编辑、版本回退及导出；新设备不生成示例记录。
- 详情内容自动填充剩余空间，不保留独立的“脚本”标题行。复制与“导出文本”“导出文档”放在同一操作行。
- 复制跟随当前选中标签：拍摄脚本、拍摄手法、口播稿、全文、原稿对照；不得固定复制全文或只复制当前镜头页。
- 视频通过“导出”菜单选择“导出文本”或“导出文档”。TXT 导出文本；文档导出为 Word 可打开的 HTML 兼容 .doc，不是原生 .docx。
- 图文历史提供“重新编辑”“复制发布文案”和“导出素材包”。当前图文有未保存修改时，打开历史前提供“保存修改并打开”“放弃修改并打开”和“取消”。
- 点击删除仅打开居中确认弹窗，展示记录标题，并说明会永久删除本机记录、脚本、原稿和版本，其他记录及已导出文件不受影响。
- 默认聚焦取消。取消、关闭和 Escape 不删除；确认后才调用删除接口。提交期间禁用重复操作并阻止关闭；失败保留记录与弹窗，显示具体原因并可重试。
- 删除图文历史前统计全部页面版本的图片数量与占用；删除范围包含该稿件全部版本及图片，已导出的文件不受影响。

## 5. 设置与账号

### 5.1 设置分类

页面名称为“设置”，以“内容设置”“系统设置”两个标签分页展示。标签与头部保持可见，内容在独立滚动容器中滚动，不带动左侧导航离开视口。

| 分类 | 配置内容 | 行为 |
| --- | --- | --- |
| 内容设置 | 公司知识库 | 支持 PDF、DOCX、TXT、MD、CSV、JSON 导入、预览、启停和删除；仅启用文档参与生成 |
| 内容设置 | 主营业务与关键词 | 分类为“业务 / 产品”“卖点”“禁用词”，作为生成上下文与约束，按本设备保存 |
| 系统设置 | API 接口配置 | “智能二创”“内容提取”“图片生成”三块独立配置并分别保存 |
| 系统设置 | 存储地址 | 选择历史与知识库数据库目录，未单独配置的图文素材跟随；下次启动迁移生效，原目录保留备份，迁移失败提示原因 |
| 系统设置 | 图文素材存储地址 | 默认跟随数据目录，可“更改素材地址”或“恢复跟随数据存储地址”；下次启动迁移，保留原目录与全部成功图片版本 |
| 系统设置 | 诊断与日志 | 提供打开本设备运行日志目录入口 |

设备密钥、日志和界面偏好仍在应用目录；图片可跟随数据目录或使用独立素材目录。数据不自动跨设备同步。同一 Windows 用户下的不同软件账号共享本机历史、知识库、素材与 API 配置；换软件账号不构成数据隔离，需要隔离时使用不同 Windows 用户或设备。

### 5.2 接口配置

- “智能二创”支持 OpenAI 兼容接口和“使用 DeepSeek 配置”。“内容提取”提供“使用 LinkDigest 配置”“使用姚安配置”和“自定义接口”；“图片生成”按图片厂商配置。各块分别点击“保存本设备接口配置”，成功后显示“已配置”。
- 快捷预设只填写表单；“测试模型连接”使用当前表单，不自动保存，也不证明余额充足。只生成视频脚本时不要求配置图片生成服务。
- 内容提取保留 LinkDigest、姚安 AIGC 与自定义接口。自定义配置支持完整 HTTPS 地址、GET／POST JSON、鉴权方式、字段路径和超时；不虚构供应商未提供的能力。
- 同一厂商 Key 留空保留原值，更换厂商需提供新 Key。配置校验与保存错误给出具体中文 Toast，不向界面或日志回显供应商敏感响应。
- API Key 使用本机系统安全存储加密，不发送至授权服务器；仍需由用户在供应商侧管理额度与撤销。加密保护静态存储，不承诺阻止当前系统用户提取 Key，或撤销已复制的 Key。
- “清空 API 配置并重新填写”须确认后清除本机三类接口配置。取消不清除；清空后必须重新填写并分别保存。

| 图片厂商 | 当前能力与边界 |
| --- | --- |
| Agnes | 支持文字生图、参考图与单图优化 |
| Seedream | 支持文字生图、参考图与单图优化，单次最多 10 张参考图 |
| GLM | 仅官方文字生图，整页提示词最多 1000 字符；参考图上传与沿用上一版图片入口不可用。读取旧图生图配置时改为文字预设并清除旧图片密钥，其他模块配置与业务素材保留 |
| Sub2API（异步生图） | 支持文字生图、参考图与沿用当前图优化；同一 API Key 提交与查询，最长等待 30 分钟，完成后下载保存。取消只停止本机等待 |

### 5.3 账号管理与登录稳定性

- 管理员可创建账号、启用／停用、重置密码和删除账号；成员不能操作账号管理接口。
- 重置密码使用明显可见的居中弹窗，校验两次输入一致和 8–128 位长度，说明将撤销目标账号所有设备会话。
- 删除账号先确认，说明不可撤销及会话撤销；内置管理员与当前登录账号受保护，已有业务历史不随账号删除。
- 每次业务操作实时校验授权；空闲时约每 30 秒、任务期间约每 15 秒检查，实际生效时间包含网络耗时。
- 只读身份查询临时连接失败、超时或响应异常时，等待 250 ms 后重试一次，每次请求上限 5 秒；登录与账号修改不自动重提。
- 已提交任务遇到临时授权不可达时，从最近一次真实授权成功起算给予最多 60 秒宽限，失败不续期；宽限内保留会话并继续等待，超期停止。后续图片提交前须重新校验成功，等待可取消；恢复后不自动重提已取消任务。
- 明确会话失效、停用、密码重置或退出时，撤销会话并取消本机任务。普通成员被管理员停用且客户端收到有效停用结果后，清除当前 Windows 用户的三类 API 配置，保留历史、知识库与素材；重新启用不恢复已清除的密钥。
- 主动退出、同设备换软件账号、普通登录失效与密码重置保留本机 API 配置。清理失败须明确提示，不误报为成功；服务端重启后可能需要重新登录。
- 授权检查写入脱敏日志，保留错误码、底层错误类型与可用 HTTP 状态。成功图片保留后端归档，不因结束时临时授权异常或重复保存失败而丢失。

## 6. LinkDigest 能力与限制

- POST 创建任务；200 读取结果，202 使用同一 jobId 轮询，最长本机等待约 150 秒，不重新 POST。单次积分上限默认 5，可配置为 1–1000 整数。
- 分开处理 caption、transcript、图片 OCR、画面文字、描述、分析要点、tags、覆盖信息和积分；不以摘要补齐缺失原稿。
- 仅访问固定 HTTPS 服务，不跟随返回的外部轮询地址或重定向。鉴权、余额／预算、限流、平台拒绝、网络和空结果分别提示。
- 停止等待、退出或停权只保证中断本机请求，不承诺取消厂商任务或退款；再次提取可能重复计费。

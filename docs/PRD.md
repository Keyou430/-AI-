# 产品需求文档 (PRD) - 视频二创AI助手 (V1.1 修订版)

## 1. 产品概述

### 1.1 产品定位

一款面向短视频创作者、企业新媒体运营人员的桌面端效能工具。支持输入抖音/小红书当下热点视频链接，提取原视频口播文案与画面结构（支持**全自动一键二创**与**仅提取后人工修改再二创**两种模式），并将原热点视频的流量骨架与企业专属知识库、**本公司主营业务关键词**深度结合，利用大语言模型（LLM）重新生成具备强商业转化属性和品牌风格的二创分镜脚本。

### 1.2 目标用户

* 短视频编导、自媒体创作者

* 企业新媒体代运营团队

* 品牌方与电商带货主播团队

## 2. 核心业务流程

系统支持 **「全自动一键二创」** 与 **「手动提取修改后再二创」** 两种工作流模式，满足不同精细度场景的需求：

| 流程阶段 | 模式一：全自动模式（一键提取并二创） | 模式二：手动分步模式（仅提取 -> 人工修改 -> 再二创） | 
| ----- | ----- | ----- | 
| **1. 输入源** | 用户在主界面粘贴抖音或小红书的热点视频分享链接，点击 **「一键提取并二创」** 按钮 | 用户在主界面粘贴抖音或小红书的热点视频分享链接，点击 **「仅提取文案」** 按钮 | 
| **2. 解析提取与人工编辑** | 系统调用第三方 API 提取原视频口播文案与画面描述，直接进入下一步 AI 二创 | 系统提取原视频口播文案与画面描述并填入左侧**可编辑文本框**；用户可手动删减冗余信息、修正错别字、改写热点切入点或调整画面描述 | 
| **3. 结合本公司业务 AI 二创** | 自动将原始提取文案、本公司业务关键词与企业知识库拼接发送给大模型生成脚本 | 用户确认修改无误后，点击 **「结合本公司业务开始二创」** 按钮，系统以**用户修改后的文案与画面描述**为准，结合本公司业务关键词与知识库生成脚本 | 
| **4. 人工干预与多轮迭代** | 针对右侧已生成的脚本，点击 **「优化脚本」** 按钮输入修改指令，基于当前上下文流式重新生成 | 同样支持点击 **「优化脚本」** 按钮输入补充修改指令（如“进一步突出本公司核心业务优势”），多轮迭代直至满意 | 

### 详细步骤说明

1. **输入源**：用户在主界面粘贴抖音或小红书的当下热点视频分享链接，并确认目标时长与运镜信息。

2. **解析提取与人工修订（新增手动干预节点）**：

   * 系统调用第三方 API，解析链接并提取原视频的口播文案及画面描述。

   * 若用户选择 **「仅提取文案」**，提取出的文本展示在左侧可编辑区域，用户可自由修改口播文本与画面描述，确认后再手动点击 **「结合本公司业务开始二创」**；若用户选择 **「一键提取并二创」**，则跳过人工停顿直接触发大模型生成。

3. **AI 二创生成（热点视频 × 本公司业务融合）**：

   * 系统读取【设置页】中的“本公司业务关键词”**（主营业务、核心产品/服务、转化卖点、违禁词）和**“公司知识库”。

   * 结合左侧当前生效的原视频文案（原始提取文本或人工修改后文本），向大模型发送 Prompt：要求提炼原热点视频的黄金前 3 秒钩子、叙事节奏与情绪共鸣点，并将其**自然嫁接至本公司业务场景与产品价值**上。

   * 大模型返回结构化的三部分内容：**拍摄脚本、拍摄手法、口播稿**。

4. **人工干预与迭代**：用户若对生成结果不满意，点击“优化脚本”按钮，输入具体的修改指令（如“语气更幽默”、“强化本公司业务痛点对比”、“加入促销信息”），系统基于当前上下文再次生成，直至用户满意。

## 3. 功能需求说明

### 3.1 主流程页 (工作台)

* **链接输入与模式触发区**：

  * 提供文本输入框，支持一键粘贴抖音/小红书分享链接（自动从口令文本中识别 URL）。

  * 提供并列的双操作按钮，支持全自动与手动两种操作路径：

    1. **「仅提取文案」按钮（次主按钮 / 手动分步模式）**：仅执行视频链接解析与文案提取，提取完成后停留在左侧编辑区等待用户手动修改，不自动调用大模型。

    2. **「一键提取并二创」按钮（主按钮 / 全自动模式）**：自动串行完成“链接提取 -> 结合本公司业务生成二创脚本”全流程。

* **提取结果展示与编辑区 (左侧)**：

  * **可编辑文本框（由原只读升级为可编辑）**：展示从原热点视频中提取出的**口播文案/原声文字**与**原片画面描述**。

  * **手动修改与状态标识**：

    * 用户可直接在文本框内增删、修改提取出的文字内容（例如剔除原视频与本公司无关的广告词、补充希望结合的业务切入角度）。

    * 当用户修改过文本后，显示“已人工编辑”状态标签，并提供 **「恢复原始提取内容」** 快捷按钮。

  * **手动触发二创入口**：在左侧编辑区底部提供显眼的 **「结合本公司业务开始二创」** 按钮。无论用户是刚执行完“仅提取文案”，还是在全自动生成后又手动修改了左侧提取文本，均可点击该按钮基于最新编辑的文本重新执行 AI 二创。

  * **异常提示**：若解析失败，需给出明确的错误提示（如：链接无效、平台不支持、API 额度耗尽），同时允许用户在未粘贴链接时直接在左侧文本框手动输入/粘贴任意热点文案进行二创。

* **二创内容展示区 (右侧主视觉)**：

  * 分 Tab 展示或分区域展示三大模块：

    1. **拍摄脚本**：以表格或结构化分镜列表形式展示（分镜头、画面动作、运镜标准、台词/环境音）。

    2. **拍摄手法**：展示运镜、空镜要求、灯光角度、首尾帧动线与节奏建议等。

    3. **口播稿**：展示结合本公司业务润色后的口播纯文本。

【输出格式】 【分镜脚本总览】共X个镜头，总时长XX秒 —————— 【镜头X | 时长区间】 ▪️人员动作分工：写明谁在哪里做什么，出镜人员与摄影师的动作均需描述清楚（需自然融入本公司业务场景或产品交互动作） ▪️运镜与拍摄执行标准：按景别、运镜手法、灯光、角度逐项写明，且必须百分百复用用户输入的运镜信息 ▪️声音内容：有口播时写概要化口播文本（结合原热点切入方式与本公司核心业务卖点）；无口播时写“仅环境音”并描述具体环境音 ——————

【脚本编排规则】

1. 根据视频总时长灵活拆分镜头，按抖音节奏排列，镜头序号严格正序递增，时间不足时不强行拆分

2. 禁止一镜到底，镜头之间通过光影变化或人物动线衔接，确保首帧连贯不跳脱

3. **热点与本公司业务深度融合**：提取原热点视频的吸睛钩子、叙事结构与情绪痛点，无缝迁移至【设置页】所配置的“本公司业务关键词”与“企业知识库”场景中，做到借势热点且业务属性鲜明，严禁生搬硬套或脱离本公司主营业务自说自话

4. 口播稿必须严格匹配对应镜头时长；若时长不足或不适合口播，则不写口播，只标注环境音

5. 纯中文输出，使用中文全角标点，严禁出现英文双引号、英文单引号、未闭合括号

6. 绝对禁止出现字幕及其他相关字段，视频画面中不得出现任何文字元素

7. 只输出分镜脚本本身，不写任何多余内容，包括解释、开场白、备注等

【输出前自查项】
□ 全文无“字幕”二字，确认画面无文字
□ 总时长与用户输入的视频时长一致
□ 镜头按序号正序排列
□ 每个镜头三字段完整
□ 已将原热点视频结构与本公司业务关键词自然结合，无脱离业务的无效镜头
□ 无英文双引号、英文单引号、未闭合括号
□ 口播时长与镜头时长匹配，不匹配则改为环境音
□ 运镜百分百复用用户输入
□ 无任何多余内容

* **迭代优化模块**：

  * 提供“优化脚本”按钮，点击弹出优化提示词输入框（内置“强化本公司业务结合度”、“黄金前3秒痛点更犀利”、“语气更幽默”、“加入促销转化引导”等快捷指令）。

  * 用户输入修改意见后，点击“重新生成”，右侧内容区流式更新。

### 3.2 历史记录页

* **记录列表 (左侧)**：

  * 基于本地 SQLite 数据库持久化存储，以卡片形式按时间倒序展示历史二创记录。

  * 卡片包含：平台 Icon（抖音/小红书）、生成的标题/摘要、生成时间、提取时长、所结合的业务关键词摘要。

  * 提供按平台筛选、关键词检索及“删除”操作。

* **详情预览 (右侧)**：

  * 点击列表卡片后，在此区域完整展示该记录的拍摄脚本、拍摄手法、口播稿以及当时用于生成的原视频（或人工修订后）文案。

  * 提供“重新编辑”（跳转回主流程页并恢复左侧文案与右侧脚本状态）和“导出”（支持导出为 TXT 或 Word）按钮。

### 3.3 设置页

* **知识库配置**：

  * 支持拖拽或点击上传本地文件（.pdf, .docx, .txt, .md 等），用于提供公司详细背景、产品手册与成功案例。

  * 列表展示已上传的知识库文件，支持启用/停用开关与删除。

* **本公司业务与关键词配置（核心升级）**：

  * 提供「本公司主营业务概述」输入框（如：“主营企业财税合规咨询与高新技术企业申报服务”或“主营精品冷萃咖啡液与办公室便携冲调饮品”），作为热点视频跨界二创的核心业务锚点。

  * 提供分类标签输入框，用户可添加全局生效的业务关键词：

    1. **核心业务/产品词**：二创脚本中必须重点植入并展现的核心业务、产品或服务名称。

    2. **目标客群痛点与转化卖点（行业黑话）**：用于承接热点视频流量、引发目标客户共鸣的痛点词与利益点。

    3. **违禁词/敏感词**：严禁在口播与画面描述中出现的极限词或竞品词。

* **API 密钥管理**：

  * **大模型 API Key**：支持配置 DeepSeek、OpenAI、通义千问等兼容接口的 API Key、Base URL 和模型名称，提供“测试连接”功能。

  * **第三方视频提取 API Key**：用于解析抖音/小红书链接的第三方接口密钥配置。

## 4. 非功能需求

* **本地化与数据安全**：用户的历史记录（SQLite）和知识库文件均优先存储在本地，避免敏感业务数据泄露（除调用 LLM 和解析 API 必须传输的数据外）。

* **响应速度与可控性**：

  * “仅提取文案”与“AI 二创生成”解耦，支持用户随时人工介入修改上游输入文本，避免原视频 ASR 识别错误直接污染大模型输出。

  * UI 需具备良好的异步加载状态（Loading、骨架屏、流式打字机输出），防止在等待大模型响应时界面卡死。

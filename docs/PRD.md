# 产品需求文档（PRD）— 视频二创 AI 助手

产品版本：1.0.13 通用版

更新日期：2026-10-27

状态：按当前源码与已完成验收更新；未实施事项见第 8 节。

## 1. 产品定位与范围

面向短视频创作者、企业新媒体运营和品牌团队的 Windows 桌面工具。用户导入抖音／小红书分享链接或手动输入素材，核对提取结果，结合公司业务、关键词与本地知识库，生成拍摄脚本、拍摄手法及口播稿。

当前采用“提取 → 人工核对或修改 → 二创 → 多轮优化”的分步流程。旧版 PRD 中并列的“一键提取并二创”入口不属于当前界面。应用仅调用真实接口，不提供仿真模式、示例结果或预置历史记录。

管理员与成员使用同一安装包，登录后按服务端角色展示权限。授权服务负责账号、权限、会话与审计；素材提取和模型生成由客户端直连用户配置的供应商，不通过授权服务转发。

## 2. 核心用户流程

| 步骤 | 用户操作 | 系统行为与完成标准 |
| --- | --- | --- |
| 登录与配置 | 使用已有账号登录，在“设置”配置内容背景、提取接口和模型 | 正式包使用远程账号服务；新设备的接口 Key、知识库、关键词与历史为空，不自动选择提取厂商 |
| 输入素材 | 粘贴完整分享文案／链接，或直接输入素材文字 | 从分享文本识别 URL，校验支持平台；保留小红书分享参数；链接框提供清除按钮 |
| 提取并核对 | 点击“提取文案与口播”，核对结果 | 仅提取，不自动生成；视频与图文采用不同的编辑内容和提示 |
| 人工编辑 | 修改口播／图文文案及画面描述，设置时长与运镜 | 原始素材与人工稿分开保留；可恢复原始提取内容 |
| 二创 | 提交当前编辑内容 | 将有效人工稿、公司背景、分类关键词和启用的知识库发送给模型，流式显示结果；生成不重复调用提取接口 |
| 优化与保存 | 输入优化指令，查看版本或历史 | 优化携带前序上下文；保存版本和原稿快照，支持回退、重新编辑、复制及导出 |

## 3. 工作台

### 3.1 链接输入与错误反馈

- 支持抖音、小红书完整分享文本和链接；剪贴板为空、读取失败、链接无效和平台不支持时，显示具体中文错误及 Toast。
- 链接框内提供可访问的清除按钮，便于重新粘贴。
- 提取或生成期间限制重复提交。提取失败保留明确原因，用户手动决定是否重试，不自动重新付费提取。
- 无链接时允许直接输入素材文案进行二创；编辑内容为空时阻止生成。

### 3.2 视频与图文结果

| 内容类型 | 编辑区默认内容 | 补充展示 | 处理边界 |
| --- | --- | --- | --- |
| 视频 | 接口实际返回的口播文字 | 发布正文、口播状态、可用的图文与覆盖详情 | 发布正文、OCR 和智能摘要不得冒充原始口播；已知视频缺少或仅返回部分口播时保留准确提示 |
| 小红书图文 | 正文、逐图 OCR／可用 OCR 汇总及画面文字 | “图文文案”标签、直接可见的素材关键词、可展开的逐图详情 | 图文不以返回口播为成功条件；不显示误导性的缺口播提示，不以未知口播时长干扰图文核对 |

图文文字按原始内容组合；有逐图 OCR 时不重复加入 OCR 汇总。图片按接口返回位置编号，空项保留，不独立承诺原帖顺序。智能图片描述和分析要点独立展示，不自动填入原文编辑区。

素材关键词优先使用接口 tags，并从原始正文／图片文字中的话题标签补齐、去重；旧记录没有 tags 时仍可从原文话题补齐。无来源时不编造关键词。素材关键词与公司业务关键词分开处理。

正文、口播、人工稿、逐图 OCR、覆盖信息和费用信息随草稿／历史保留。历史中的原稿对照与复制使用对应的真实素材，图文不展示为空的原始口播。人工修改优先用于二创，保留原始来源供核对。

删除以下两条冗余提示，但保留缺图、转写失败等真实异常：

- “口播已返回，但完整性待核对，请查看提取说明。”
- “厂商注明有未读取内容，可能涉及评论、画面或其他素材；本结果不是整帖完整副本。”

### 3.3 编辑与生成

- Composer 支持自动增高、粘贴／拖入文字、焦点反馈、字数提示及 Ctrl／Command + Enter 提交；中文输入法组合输入期间不触发提交，忙碌期间限制编辑和重复操作。
- 用户可设置目标时长和指定运镜。模型提示要求结合公司业务与素材结构，按顺序输出分镜，包含人员动作、运镜／拍摄标准及声音内容。
- 输出要求包含总时长、镜头时序、指定运镜、违禁词与不出现字幕等约束。约束由提示与结果检查辅助实现，不承诺所有模型响应天然合规，用户仍需核对。
- 结果以“拍摄脚本”“拍摄手法”“口播稿”“全文”标签展示；具备来源记录时提供“原稿对照”。拍摄脚本与拍摄手法支持按镜头分页，复制仍按当前标签获取对应完整内容。
- 优化提交当前上下文和修改指令，保存版本快照；版本回退保留历史版本。普通二创创建新的历史记录，优化在当前记录中追加版本。
- 切换记录时隔离生成结果，避免旧请求写入另一条记录。保存失败需明确提示，并保留已生成内容。

## 4. 历史记录与删除保护

- SQLite 保存历史，支持筛选、检索、详情、重新编辑、版本回退及导出；新设备不生成示例记录。
- 详情内容自动填充剩余空间，不保留独立的“脚本”标题行。复制与“导出文本”“导出文档”放在同一操作行。
- 复制跟随当前选中标签：拍摄脚本、拍摄手法、口播稿、全文、原稿对照；不得固定复制全文或只复制当前镜头页。
- TXT 导出文本；文档导出为 Word 可打开的 HTML 兼容 .doc，不是原生 .docx。
- 点击删除仅打开居中确认弹窗，展示记录标题，并说明会永久删除本机记录、脚本、原稿和版本，其他记录及已导出文件不受影响。
- 默认聚焦取消。取消、关闭和 Escape 不删除；确认后才调用删除接口。提交期间禁用重复操作并阻止关闭；失败保留记录与弹窗，显示具体原因并可重试。

## 5. 设置与账号

### 5.1 设置分类

页面名称为“设置”，以“内容设置”“系统设置”两个标签分页展示。标签与头部保持可见，内容在独立滚动容器中滚动，不带动左侧导航离开视口。

| 分类 | 配置内容 | 行为 |
| --- | --- | --- |
| 内容设置 | 公司知识库 | 支持 PDF、DOCX、TXT、MD、CSV 导入、预览、启停和删除；仅启用文档参与生成 |
| 内容设置 | 公司主营业务、业务词、痛点／卖点词、违禁词 | 作为生成上下文与约束，按本设备保存 |
| 系统设置 | 模型与内容提取接口 | 模型 Key、Base URL、模型名；提取厂商、Key、预算及自定义协议配置 |
| 系统设置 | 存储地址 | 选择历史与知识库数据库目录，下次启动迁移生效，原目录保留备份；迁移失败继续使用原目录并提示 |
| 系统设置 | 诊断与日志 | 提供打开本设备运行日志目录入口 |

迁移仅针对历史与知识库数据库；设备密钥、日志和界面偏好仍在应用目录。数据不自动跨设备同步；同一设备上的不同账号共享本机业务数据。

### 5.2 接口配置

- 模型支持 OpenAI 兼容接口与 DeepSeek 配置预设，使用用户自己的 Key。预设不是已配置成功或已验证余额的凭据。
- 内容提取保留 LinkDigest、姚安 AIGC 与自定义接口。自定义配置支持完整 HTTPS 地址、GET／POST JSON、鉴权方式、字段路径和超时；不虚构供应商未提供的能力。
- 同一厂商 Key 留空保留原值，更换厂商需提供新 Key。配置校验与保存错误给出具体中文 Toast，不向界面或日志回显供应商敏感响应。
- API Key 使用本机系统安全存储加密，不发送至授权服务器；仍需由用户在供应商侧管理额度与撤销。

### 5.3 账号管理与登录稳定性

- 管理员可创建账号、启用／停用、重置密码和删除账号；成员不能操作账号管理接口。
- 重置密码使用明显可见的居中弹窗，校验两次输入一致和 8–128 位长度，说明将撤销目标账号所有设备会话。
- 删除账号先确认，说明不可撤销及会话撤销；内置管理员与当前登录账号受保护，已有业务历史不随账号删除。
- 每次业务操作校验授权；空闲时约每 30 秒、任务期间约每秒检查，实际生效时间包含网络耗时。
- 服务明确返回会话失效／账号停用时撤销登录并中断任务；退出、密码重置或服务端会话到期仍需重新登录。
- 授权服务暂时不可达、超时、503 或响应异常时，保留本地会话，拒绝当前需授权操作并中断在途任务；后台继续检查。恢复且服务端会话仍有效后可重试，不要求再次登录，也不自动恢复原任务。
- 授权检查失败写入脱敏日志，保留错误码、底层错误类型与可用 HTTP 状态，避免把网络失败误报为登录失效。服务端重启会撤销内存会话，本次未改变该机制。

## 6. LinkDigest 能力与限制

- POST 创建任务；200 读取结果，202 使用同一 jobId 轮询，最长本机等待约 150 秒，不重新 POST。单次积分上限默认 5，可配置为 1–1000 整数。
- 分开处理 caption、transcript、图片 OCR、画面文字、描述、分析要点、tags、覆盖信息和积分；不以摘要补齐缺失原稿。
- 仅访问固定 HTTPS 服务，不跟随返回的外部轮询地址或重定向。鉴权、余额／预算、限流、平台拒绝、网络和空结果分别提示。
- 停止等待、退出或停权只保证中断本机请求，不承诺取消厂商任务或退款；再次提取可能重复计费。
- 供应商或平台可能拒绝读取，不保证任意链接成功或完整覆盖。当前不内置浏览器扩展、本地媒体 capture、批量搜索、下载或绕过平台限制能力。

## 7. 视觉、适配与工程边界

- 保留当前桌面导航、素材编辑和结果展示的核心布局，减少无用标题、提示及装饰。品牌采用 semantic CSS variables、DM Sans Variable 与中文后备字体，统一字号、间距、圆角和状态颜色。
- 沿用 Electron、React 18、TypeScript、Tailwind CSS v3、Zustand 和当前依赖。通用交互优先复用现有 Base UI 组件；存量 Radix 依赖未要求整体替换。动效使用 motion/react，尊重减少动态效果偏好。
- 桌面侧栏支持收起／展开并保存状态；窄屏使用导航抽屉，工作台提供素材／结果切换。限制整体视口滚动，分别处理内容滚动、触摸目标、安全区与弹窗高度。
- 提供表单标签、可访问名称、键盘操作、焦点管理、状态与错误反馈；不据此宣称已完成全面 WCAG 认证。
- 正式包隐藏 File、Edit、View、Window 等无用应用菜单。界面操作以中文为主，保留供应商品牌、API／OCR 等必要技术标识。
- 运行日志按日期／大小轮转，保留 14 天且最多 20 个文件，排除密码、密钥和业务正文。授权服务器不保存本机业务数据。

## 8. 待处理事项与非承诺范围

以下为已排查但尚未新增确认机制的操作，不计入本次已完成能力：

- 知识库直接删除：建议确认文件名与后续生成影响，失败保留原项。
- 恢复原始提取、重新填入图文、再次提取或加载历史：可能覆盖当前人工稿；建议仅在存在未保存修改时确认或提供撤销。
- 普通二创启动会替换当前展示与版本状态：建议保留旧稿快照至成功；当前不删除先前已保存的历史记录。
- 停用账号：建议说明多设备下线与任务中断，再确认执行；启用无需增加同等确认。
- 关键词移除、知识库启停等可恢复操作优先考虑撤销和明确反馈，避免所有操作都弹窗。

安装包尚未完成代码签名及两台实体设备的安装／升级／卸载验收。已保存真实 LinkDigest 响应的回放验证不代表所有链接成功率、口播准确率、商业模型质量或完整性达标。本次客户端更新不包含授权服务器重新部署。

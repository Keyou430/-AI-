# LinkDigest 接入与验收（1.0.6）

## 用户操作

1. 安装当前通用版，在系统设置的“内容提取”选择 LinkDigest。
2. 填入自己的 LinkDigest API Key，设置单次积分上限（默认 5，允许 1–1000 整数），点击保存。
3. 二创模型仍需单独配置；可使用 DeepSeek 预设与自己的模型 Key。
4. 关闭仿真模式，粘贴抖音／小红书完整分享链接，点击提取。小红书的 xsec_token 等分享参数会保留。
5. 发布正文、原始口播与详情分开显示。图文可展开详情，点击“将正文／OCR 填入编辑区”；该操作替换当前编辑稿，不改变原始素材。
6. 人工核对修改后再二创；生成和多轮优化不重新调用提取接口。原始片段、OCR、描述与覆盖说明随历史和草稿保存。

Key 通过本机系统安全存储加密保存，留空保留，填写新值覆盖；更换厂商必须填写对应新 Key，新设备为空。服务器仍只负责账号鉴权；不接收供应商 Key 或业务内容。本轮不改变服务器部署。

## 协议与安全边界

- POST https://linkdigest.dev/api/v1/digest，Bearer 鉴权；JSON 为 url、format=json、depth=full、partial_ok=false、max_credits=前端设定值。
- 200：读取结果；202：记住 jobId，每次仅 GET /api/v1/digest/{jobId}?wait=20。连续即时返回时至少间隔 1 秒，不重新 POST。
- 仅访问固定 HTTPS 源站，拒绝 HTTP 重定向；不跟随响应中的 poll 地址；任务编号限定为安全字符且不允许中途替换。
- 全流程等待最多约 150 秒，小于现有远程授权任务上限。退出、停权、会话撤销会中断本机轮询。没有调用厂商取消接口，停止等待不保证任务取消或退款。
- 超时与网络异常不自动重提，提示厂商可能仍在处理，再次提取可能重复计费。
- 400／401／402／403／422／429／503 等状态映射为明确提示。错误正文、原始供应商消息及 poll 地址不回显到错误提示或日志，避免包含密钥。
- 发布正文取 caption；口播从 transcript[].text 合并，另保留时间片段；OCR、on_screen、images、key_points 单独保留。摘要不补充为原始口播。
- 图文没有口播时不伪造口播成功；允许人工选取正文及 OCR 二创。图片按返回位置编号，识别失败的空项不删除，不独立保证供应商返回顺序与原帖相同。
- partial、read_seconds、图片覆盖数量、degraded 与未捕获内容生成完整性提示；缺少覆盖凭据时明确不可确认完整性。未返回正文、口播或图文时失败，不用摘要冒充原稿。

## 未包含的能力

不接入批量搜索、批量对比、翻译、消费者洞察或付费爆款拆解，不下载视频／音频，不绕过登录或平台限制。抖音被平台拒绝时只提示厂商可用替代方式，当前 EXE 不内置浏览器扩展或本地文件 capture 流程。

## 验证范围

本次自动化与桌面验收使用协议样本，不调用 LinkDigest 或 DeepSeek 商业 API，不代表真实链接成功率与准确度。需在前端填写有效 Key，使用有权处理的抖音视频、小红书视频与多图笔记，逐项核对正文、口播、图片顺序、费用和失败提示。

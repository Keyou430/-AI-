## 已复现问题（修复前）

### F01：旧图与当前草稿不同步，导出清单仍提示图片检查通过（P1，AUD-05）

- 具体环节：图片优化失败后的核对与导出。
- 触发条件：已有成功图片并勾选“图内文字已核对”；修改该页图内文字，提交重生成；供应商返回 HTTP 503；随后点击导出。
- 复现结果：稿件文字变为“AUD-05 新版图内文字需要替换旧版”，当前图片的生成指纹仍是“图文封面”；旧图片被保留，人工核对仍勾选。导出的 01.png 仍为旧图，而内部清单显示“通过：每页当前图片，每页均有当前图”，没有该页待重生成／内容失配提醒。第 2 页未核对提示仍会显示。
- 现有提示：编辑界面确实显示生成失败、待重生成和重试入口，问题不是完全没有失败提示，而是导出与自查未延续这项状态。
- 影响范围：对已有图片进行文字、画面或风格调整后生成失败的页面；可能把旧内容混入准备发布的素材包。不是全局界面死锁。
- 原因定位：imageTextChecks 只判断 assetId 是否存在及版本比例，不比较 pageRenderKey 与 renderedKey；内部核对清单未纳入 page.error 或待重生成状态。人工核对标记仍指向旧成功版本，界面没有区分“旧图已核对”和“当前改稿已完成”。
- 相关代码：electron/services/imageTextReview.ts:14、75；electron/services/imageTextIpc.ts:135；src/store/useImageTextStore.ts:131。
- 修复方向：把待重生成、失败与当前图失配纳入自查、导出提示和内部清单；当前稿件的完成状态与旧成功版本的人工核对状态分开表达，保留旧图用于恢复。
- 证据：flow-audit.json / AUD-05；AUD-05-内部核对.txt；AUD-05-失败保留旧图但仍勾选已核对.png。

### F02：全局优化预览返回，覆盖等待期间的人工输入（P2，AUD-04）

- 具体环节：全局优化弹窗中的“生成优化预览”。
- 触发条件：提交优化预览，在模型请求等待期间继续修改发布正文。
- 复现结果：正文输入框仍可编辑，已输入“AUD-04 用户在等待期间补充的真实正文”；响应返回后恢复成请求开始前的“只修改发布正文”。没有冲突提示。
- 影响范围：较慢的文本策划请求中继续编辑的用户；被覆盖的文字需要重新输入。相同的整份草稿替换机制也涉及风格、比例、逐页内容和分页结构，其他字段没有逐一注入验证。
- 原因定位：输入框和结构编辑在 busy 时未统一禁用；请求以旧草稿生成预览，返回时 setOptimization({draft: preview}) 直接替换整份本地编辑状态，未校验编辑修订号。
- 相关代码：src/views/ImageTextView.tsx:75、167、173；src/store/useImageTextStore.ts:85。
- 修复方向：最小方案是在预览期间禁用相关编辑；如需允许继续编辑，则加入修订判断，避免静默覆盖。
- 临时操作：等待预览完成后再继续手工编辑。

### F03：参考素材达到上限后无法释放名额（P2，AUD-06，条件性硬阻塞）

- 具体环节：图片优化中补传实际场景图。
- 触发条件：同一稿件累计保存 30 张参考图。取消优化也会保留已归档素材，所以未使用的图同样计数。
- 复现结果：再次上传被提示“整套最多保存 30 张参考图”；弹窗只有补传、取消与重生成等操作，未提供删除／移除参考素材入口。取消页面绑定只改变 referenceIds，不减少稿件 references 数量。
- 影响范围：当前记录后续不能再添加新的实景或风格素材；既有素材仍可选择，文案及已有图片不被锁死。经常补传和取消优化的用户也可能累积触发。
- 原因定位：后端限制 references.length + 新增数量 <= 30，但界面和 store 没有移除素材池条目的操作。
- 相关代码：electron/services/imageTextIpc.ts:103；src/store/useImageTextStore.ts:157；src/views/ImageTextView.tsx:89、161。
- 修复方向：提供安全的移除／替换入口；版本仍引用的图片应保留在版本索引中，不能直接删除影响历史。
- 临时操作：复用已导入素材；当前稿件没有释放名额的界面路径。
- 证据：flow-audit.json / AUD-06；AUD-06-参考图上限提示.png。

### F04：从历史重新编辑，静默丢失未保存修改（P2，AUD-08）

- 具体环节：首次确认前的人工编辑 → 历史记录 → 重新编辑同一稿件。
- 触发条件：修改正文但尚未点击保存或确认生成，进入历史并重新打开该记录。
- 复现结果：没有未保存提示，正文从“AUD-08 需要保留的人工修改”恢复为数据库中的“只修改发布正文”。单纯切换侧栏后直接回图文模块不等同于这个复现步骤。
- 影响范围：未保存的图文修改；已有持久化历史不受损，但用户需要重做修改。
- 原因定位：updateDraft 仅更新内存，loadDraft 不检查当前是否有未保存改动，直接以历史副本替换。
- 相关代码：src/store/useImageTextStore.ts:49、183；src/views/HistoryView.tsx:278。
- 修复方向：加载历史前比较当前稿件与保存版本，必要时提供保留／放弃操作；不必扩展为全应用自动保存。
- 临时操作：进入历史并重新打开稿件之前先点击保存。

### F05：生图密钥明确无效后仍继续请求后续页面（P2，AUD-09）

- 具体环节：整套受影响图片生成循环。
- 触发条件：有 2 个待生成页面，Agnes 持续返回 HTTP 401。
- 复现结果：先后发出 2 次均失败的请求，没有在第一次明确鉴权失败后停止整套任务。此处是继续下一页，不是同页自动重试。
- 影响范围：密钥无效时整套逐页失败，增加无效请求及等待；测试没有验证供应商是否计费，也不推断会扣费。
- 原因定位：供应商 HTTP 401 被转换为普通错误；主进程返回通用错误码；前端只会因本应用 AUTH_REQUIRED、ACCOUNT_DISABLED、AUTH_UNAVAILABLE 停止循环，其他错误均记为单页失败后继续。
- 相关代码：electron/services/agnesImageService.ts:27；electron/main.ts:90；src/store/useImageTextStore.ts:116、123、131。
- 修复方向：保留可机器判断的供应商错误类别；密钥、额度等整套前置条件错误应停止后续页；单页内容或图片格式问题可继续其他页。
- 临时操作：出现明确密钥错误时停止任务，修正配置后再重试未完成页。

# Agnes、Seedream、GLM 生图适配与验收

日期：2026-11-02。本轮三厂商源码与随后完成的删除跳转修复已纳入 1.0.20 安装包；正式包交付验证见文末。

## 设置与使用

系统设置已删除“兼容”字样。图片生成按 Agnes、Seedream、GLM 三家厂商配置，提供对应快捷按钮和厂商下拉选项；切换厂商自动填入接口完整地址和模型名称，清空其他厂商未保存的密钥输入。预设只填表，用户填写 API Key 并点击保存后生效。已保存密钥本机加密存储，页面不回显，其他模块配置保留。

| 厂商 | 系统预设模型 | 接口完整地址 |
| --- | --- | --- |
| Agnes | agnes-image-2.5-flash | https://apihub.agnes-ai.com/v1/images/generations |
| Seedream | doubao-seedream-5-0-pro-260628 | https://ark.cn-beijing.volces.com/api/v3/images/generations |
| GLM | glm-image | https://open.bigmodel.cn/api/paas/v4/images/generations |

Agnes 和 Seedream 继续使用既有独立协议，支持逐页参考图和上一版图片参考。GLM 使用 model、prompt、size 发起请求，读取 data[0].url 后下载图片并保存到现有资产库，纳入统一历史和单页版本。图片下载不携带模型 API Key，临时图片地址及签名参数不进入业务记录或日志。

GLM 预设为文字生图：设置页提示不支持参考图或沿用当前图作参考；整页提示词（含系统规则、风格、画面及图内文字）超过 1000 字符时拒绝请求，不截断内容。单页优化可修改文字与画面要求后重新生成，需关闭上一版参考并移除本页及整套参考图。整套任务遇到能力限制会停止后续页，保留旧图，修改后可继续重试。

GLM 协议依据为智谱开放平台图像生成文档：

`https://docs.bigmodel.cn/api-reference/模型-api/图像生成`

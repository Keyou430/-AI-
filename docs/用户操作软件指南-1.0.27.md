# 用户操作软件指南

适用版本：视频二创 AI 助手 1.0.27
整理日期：2026年11月5日
适用人员：新媒体运营、内容创作人员、账号管理员

本软件用于把抖音、小红书视频素材整理成二创脚本，或把小红书图文整理为图片及配套发布文案。按“安装绑定 → 登录 → 配置本机接口与内容背景 → 提取核对 → 生成优化 → 人工检查 → 导出”的顺序操作。软件生成创作素材，发布到平台仍需人工完成。

## 1 使用前先准备

### 1.1 向管理员领取

| 需要的内容 | 用途 |
| --- | --- |
| Windows x64 1.0.27 安装包 | 文件名 video-remix-universal-setup-1.0.27.exe |
| 授权服务器 HTTPS 根地址 | 首次安装绑定；以管理员提供的地址为准 |
| 软件账号与密码 | 登录和权限校验，成员不能自行注册账号 |
| 智能二创接口 | 接口地址、模型名、对应 API Key，用于脚本与图文策划 |
| 内容提取接口 | 服务商与 API Key，用于从分享链接提取原素材 |
| 图片生成接口 | 需要图文成图时准备；与智能二创分别配置 |
| 公司资料与素材 | 业务背景、关键词、可信知识库、实际场景参考图 |

管理员和成员安装同一份软件。管理员额外拥有“账号管理”入口；两种角色都可以设置本机接口。软件账号密码、供应商 API Key 和服务器运维密码是不同凭据。

### 1.2 本机数据规则

历史、知识库、素材和 API 配置不会自动跨设备同步。使用同一 Windows 用户运行本软件时，不同软件账号共用这些本机资料与配置；切换软件账号不能隔离业务资料。需要分离员工工作环境时使用独立 Windows 用户或设备。

API Key 在本机加密保存。更换设备或 Windows 用户需重新配置；不要认为登录相同软件账号会自动取回旧 Key。管理员停用成员后，客户端收到停用信息会清除共用的 API 配置，但保留业务历史和素材。

## 2 安装 绑定和登录

### 2.1 首次安装

1. 运行管理员提供的 1.0.27 安装包，按向导选择安装位置。
2. 在“绑定授权服务器”页填写管理员提供的 HTTPS 根地址，例如 https://auth.example.com。
3. 不要在地址后追加 /health、/v1 或其他路径，不要填写账号密码、问号参数或片段。
4. 点击下一步，等待服务器验证。验证通过后，核对“绑定后无法在软件中修改服务器地址”的确认提示，再继续安装。
5. 启动软件，在“登录视频二创助手”填写软件账号和密码，点击“登录”。

首次安装需要联网，证书错误、网络超时或接口不匹配均会阻止绑定。服务器地址由管理员决定，不一定是示例域名，也不一定是历史正式 IP。正式远程版的管理员由服务器初始化，用户无需在客户端创建初始管理员。

### 2.2 升级和更换地址

正常升级直接运行新安装包，保留已有绑定、API 设置和本机业务数据。旧固定地址版本直接升级到 1.0.27 时，沿用该安装包内的兼容地址，不会弹出新的地址填写页。

绑定后没有修改服务器地址的入口，网络故障也不会解除绑定。确需更换服务器，先保存稿件、备份业务资料并准备重新配置的 Key，再使用 1.0.27 的卸载程序卸载、重装和重新绑定。主动卸载会清除绑定和本机 API 设置，保留数据库、知识库、历史及业务素材；旧版卸载程序的行为不能据此推定。

### 2.3 登录与退出

账号忘记密码或被停用时联系管理员。当前没有成员自助注册或找回密码入口。关闭并重新启动软件、服务端重启、会话到期或密码重置后可能需要重新登录。

使用侧栏“退出登录”结束当前会话。主动退出及同设备换号保留 API 配置，不等于清空本机资料。退出会取消本机正在等待的任务，但供应商侧已提交的任务可能继续执行。

## 4 首次配置

### 4.1 配置智能二创接口

进入“设置 → 系统设置 → API 接口配置”，在“智能二创”卡片操作：

1. 点击“使用 DeepSeek 配置”，或填写自定义接口。
2. 核对接口基础地址、模型名与该服务商 API Key。当前快捷预设为 https://api.deepseek.com 和 deepseek-flash，实际可用模型与额度以服务商账号为准。
3. 可点击“测试模型连接”，检查当前表单是否可连接。测试不会自动保存配置，也可能产生供应商调用费用。
4. 点击“保存本设备接口配置”，看到保存成功提示后再开始生成。

每张配置卡片分别保存；点击快捷预设只填入表单，不会自动保存。同一服务商修改非密钥字段时，密钥留空可保留已存值；更换服务商时填写新服务商对应的 Key。

### 4.2 配置内容提取接口

在“内容提取”卡片选择服务商，填写对应 Key 并点击“保存本设备接口配置”。

| 选项 | 适用情况与注意事项 |
| --- | --- |
| 使用 LinkDigest 配置 | 提取抖音或小红书内容；可返回转写、图文及补充信息，实际能力以厂商结果为准 |
| 使用姚安配置 | 视频转文字，按链接平台选择接口；不需要另外填写语音识别密钥 |
| 自定义接口 | 高级配置完整 HTTPS 地址、GET 或 POST、鉴权与字段路径；由管理员提供可用参数 |

LinkDigest 的“单次提取积分上限”默认 5，可设置 1 至 1000。超出预算、平台拒绝、余额不足或限流时按提示处理。再次点击提取会再次请求厂商，可能重复产生费用；不要连续点击尝试掩盖错误。

内容提取服务并不保证每条链接都成功，也不保证取回全部原文。图片 OCR、画面描述、屏幕文字和 AI 要点是不同内容，不能把摘要或描述当作原帖完整文字。

### 4.3 配置图片生成接口

在“图片生成”卡片选择协议或快捷配置，核对接口地址、模型与 Key，再单独保存。以下为软件当前预设能力，不代表已完成你的真实商业账号联调：

| 协议 | 当前使用方式与限制 |
| --- | --- |
| Agnes | 预设模型 agnes-image-2.5-flash，1K，支持参考图与沿用当前图优化 |
| Seedream | 预设模型 doubao-seedream-5-0-pro-260628，2K，单次最多 10 张参考图，模型须支持 Base64 图片返回 |
| GLM | 预设模型 glm-image，仅支持文字生图；整页提示词最多 1000 字符，不能上传参考图或沿用上一版图片 |
| Sub2API 异步生图 | 预设模型 gpt-image-2；同一 Key 提交与查询任务，支持文字及参考图生成，最长等待 30 分钟 |

快捷按钮分别为“使用 Agnes 配置”“使用 Seedream 配置”“使用 GLM 配置”“使用 Sub2API（异步生图）配置”。接口地址由预设自动填入，仍需核对管理员提供的信息；不要把一个平台的 Key 填到另一个平台。

旧 GLM 图生图配置会迁移为官方文字预设并清除旧图片密钥，需要重新填写智谱 Key。使用参考图时改用软件支持的其他协议。切换协议后先保存，再回到图文页操作。

### 4.4 填写内容背景和知识库

进入“设置 → 内容设置”。在“业务与关键词”填写产品、服务和目标受众；关键词分为“业务 / 产品”“卖点”“禁用词”，选择分类后添加。

在知识库点击“导入文档”，或将文件拖入知识库区域。支持 TXT、MD、PDF、DOCX、CSV、JSON；导入后可预览、启用或停用、删除。只有启用的文档参与创作。扫描型 PDF 或复杂文档如提取不全，先转成可复制的文字再导入。

涉及价格、参数和服务承诺，应在知识库提供明确依据。生成内容仍需人工核对，软件不能为缺少依据的商业事实背书。删除知识库条目前先确认当前内容是否仍需使用；无需等到生成时才补充关键资料。

## 5 视频脚本二创

### 5.1 从分享链接开始

1. 打开“二创工作台”，把抖音或小红书分享链接粘贴到顶部“素材分享链接”。也可使用粘贴按钮。
2. 点击“提取文案”，等待返回。提取与生成脚本是两步，不会因提取成功就自动调用模型生成视频脚本。
3. 核对左侧“口播文案”和“画面描述”。转写缺失、错别字、产品名称和数字应先修正，再生成。
4. 展开“生成选项”，设置目标时长 6 至 180 秒，可选填“指定运镜”。
5. 确认“设置”中的公司资料和启用知识库正确，点击“生成二创脚本”。
6. 在结果区检查“拍摄脚本”“拍摄手法”“口播稿”“全文”；有来源时可查看“原稿对照”。

软件按提取结果分流：小红书图文进入图文模块，视频进入工作台；无法确定时出现内容类型选择。请按真实素材类型选择，不要只因没有口播就判定是图文。

### 5.2 直接输入文案

没有可用链接时，可直接在“口播文案”输入需要改写的文字，按需补充画面描述、目标时长和运镜，再点击“生成二创脚本”。手动文案生成需要智能二创接口，不需要先调用内容提取接口。

修改已提取文案时，生成使用当前人工修订的内容。发布前对照原始提取内容和本次输入，避免误把未核实的描述当成事实。

### 5.3 优化与版本

点击结果区“优化脚本”，输入明确修改意见，例如“保留产品事实，缩短第二个镜头，把结尾改为自然收束”，再点击“发送并优化”；可用 Ctrl + 回车提交。当前脚本及对话上下文会参与优化。

可在版本记录中查看并回退已有版本。生成成功会保存到历史；如提示“脚本已生成，但保存历史失败”，先复制结果并保留当前窗口，再按错误处理，不能认为已经持久保存。

### 5.4 复制与导出

结果区可复制当前视图内容；需要文件时进入“历史记录”，选中视频记录并使用“导出”。可导出 TXT 或 Word 兼容的 .doc 文档。软件当前视频导出不是原生 .docx 格式；如需标准 DOCX，可用 Word 或 WPS 打开后另存为 DOCX。

自动检查项仅辅助核对。发布或交给拍摄人员前，人工确认事实、禁用词、口播长度、镜头安排、商业承诺及素材使用范围。

## 6 小红书图文二创

### 6.1 提取并核对草案

1. 打开“小红书图文”，粘贴小红书图文分享链接，点击“提取并继续”。也可从工作台提取后自动进入该模块。
2. 等待原帖内容与策划草案显示。策划会使用智能二创接口；图片生成需要后面明确确认。
3. 在“文案”核对发布标题、配套发布正文和话题；在“逐图”检查每一图的“图片内文字”“画面要求”。
4. 需要时使用“增加一图 → 往前增加／往后增加”，或“删除当前图”。整套保留 1 至 30 张，至少一张。
5. 在“风格”调整整套风格；在“素材”检查原帖素材并补充参考图。必要时点击“重新策划草案”，该操作会重新调用文本模型。
6. 选择“整套图片比例”，核对张数，再点击“确认文案、张数及比例，开始生成 N 张图片”。

当前可选比例为 1:1、3:4、4:3、16:9、9:16、2:3、3:2、21:9。实际尺寸和质量取决于所用图片服务。明确确认前不会调用生图接口，确认后无需逐页再次确认。

### 6.2 使用参考图

支持参考图的协议可在“素材”中“补传原帖参考图”或“上传实际场景参考图（可选）”。原帖图用于风格与比例参考，实际场景图用于保留关键外观；生成后可在指定图片优化时按页补充绑定。

支持 PNG、JPG、JPEG、WEBP，单张不超过 20 MB；稿件参考素材总数最多 30，仍受所选服务商单次上限限制。参考图不会保证生成结果完全复刻实际产品，必须人工比对。

GLM 当前只支持文字生图，参考图上传与上一版图片参考入口不可用。旧稿件已有参考绑定时，按提示移除或改用支持参考图的协议。移除参考图会释放名额并解除当前绑定；历史文件保留，取消优化不会撤销已执行的素材移除。

### 6.3 查看生成进度与重试

生成过程中查看顶部状态和右侧“图片预览”。需要停止时点击“取消任务”。失败或未完成页面可使用“继续／重试 N 张未完成图片”；已成功的图片会保留，不必重新提取整篇内容。

Sub2API 提交后异步查询，可能长时间显示等待。取消只停止本机等待，供应商任务可能继续执行和计费；重新提交前先判断原任务状态，避免重复费用。

### 6.4 单图与全局优化

| 操作 | 适用情形与行为 |
| --- | --- |
| 图片优化 | 仅修改指定图片的文字或画面要求，可补传本页场景图，再“优化并重生成本图” |
| 附带上一版图片 | 支持参考图时可使用；只改文字默认开启，改画面默认关闭，提交前核对 |
| 全局优化 | 修改整套发布文案、风格、比例或逐页内容，先查看预计重生成页数和原因 |
| 仅更新文案 | 只修改发布标题、正文或话题时，不触发图片生成 |
| 生成优化预览 | 填写全局优化指令时先由文本模型策划预览，核对后再“应用全局优化” |

改变整套风格或比例通常会影响全部页面。提交前看清预计生成数量；已经成功的旧图片版本会保留，可通过“图片版本”切换查看。

### 6.5 核对 保存和导出

逐页检查图内文字、数字、产品外观、人物与场景，检查完成后勾选“图内文字已核对”。重新生成或切换版本后需重新核对，不能沿用旧的勾选状态。

点击顶部“保存”并确认成功提示。使用“复制文案”或历史中的“复制发布文案”取得标题、正文及话题；点击“导出素材包”选择目标目录，软件会新建“小红书图文-…”文件夹。

导出目录包含按顺序编号的 PNG 图片、发布文案.txt 和内部核对.txt。当前导出是文件夹而不是 ZIP；没有成功图片的页面会被跳过，因此导出后要检查图片数量和顺序。“内部核对.txt”供内部审核，不应原样作为发布正文。

## 7 历史记录和资料保存

### 7.1 查找与重新编辑

进入“历史记录”，可按全部内容、视频或图文筛选，结合平台筛选和搜索查找。选中记录查看详情；视频可复制、导出或“重新编辑”，图文可重新编辑、复制发布文案或导出素材包。

打开另一份图文历史时，如果当前稿件有未保存修改，按弹窗选择“保存修改并打开”“放弃修改并打开”或“取消”。先确认保存成功，避免把未完成稿件替换掉。

### 7.2 删除历史

点击删除后核对弹窗中的记录标题，再确认。删除不可撤销；视频会删除本机该记录的脚本、原稿及版本。图文会统计并删除该稿件的全部页面版本和相应图片文件，确认前核对图片数量与占用空间。

其他历史和已导出的文件不受该记录删除影响。需要保留的内容先导出并另做备份，不要把“重新生成”当作恢复已删除内容的方法。

### 7.3 修改存储位置

进入“设置 → 系统设置”。“存储地址”保存历史与知识库，未单独设置的图文素材也跟随该地址。点击“更改存储地址”后，迁移在下次启动生效，原目录保留备份。

“图文素材存储地址”可独立指定，也可“恢复跟随数据存储地址”。迁移同样在下次启动执行，保留全部成功图片版本，期间空间可能暂时翻倍。重启后检查当前地址、历史和图片，确认无误再考虑清理旧目录备份。

更改业务存储地址不会移动设备 API 配置、授权绑定、日志或界面偏好。备份应同时考虑实际业务库、独立素材目录及已导出文件；只复制程序安装文件夹不等于备份业务数据。

## 8 账号管理员操作

本节仅管理员使用。进入侧栏“账号管理”。成员请联系管理员处理，不要修改本机文件尝试改变角色。

### 8.1 新增账号

填写账号、姓名、初始密码和角色，点击“新增账号”。账号为 3 至 50 位字母、数字、下划线、点或短横线；姓名为 1 至 100 字；密码为 8 至 128 位。角色可选“成员”或“管理员”，按实际职责分配并通过受控渠道交付凭据。

### 8.2 停用 启用 重置和删除

| 操作 | 登录与数据影响 |
| --- | --- |
| 停用成员 | 撤销会话，收到停用信息的客户端清除当前 Windows 用户的三类 API 配置；业务资料保留 |
| 重新启用 | 可重新登录，已清除的旧 Key 不恢复，需重新填写 |
| 重置密码 | 在弹窗输入并确认新密码；所有设备旧会话失效，API 配置保留 |
| 删除账号 | 不可撤销，账号无法再登录，原会话失效；客户端业务历史不自动删除 |
| 普通退出或换号 | API 配置和本机资料保留 |

不能停用或删除内置 admin 及当前登录账号。重置当前管理员自己的密码后会要求重新登录。清理 API 设置只移除本地保存值，不会撤销厂商 Key，也不能取回已复制或导出的资料；离职或密钥泄露时还需在供应商平台管理额度及撤销 Key。

## 9 配置清空和故障处理

### 9.1 主动清空 API 配置

在“设置 → 系统设置 → API 接口配置”点击“清空 API 配置并重新填写”，核对确认框后选择“确认清空”。该操作清除智能二创、内容提取、图片生成三类地址、模型和 Key，需要分别重新填写保存；不清除授权绑定、历史和知识库。

不要把清空配置当作普通网络故障的默认处理方式。现有 Key 可能无法从软件中找回，应先确认已具备重新配置条件。

### 9.2 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 安装提示服务器验证失败 | 核对管理员提供的 HTTPS 根地址、网络和证书；联系管理员检查健康及授权接口 |
| 提示授权绑定无效 | 保存资料后按提示使用 1.0.27 卸载重装；会清除 API 配置，不要随意删除绑定文件 |
| 账号密码正确仍无法登录 | 核对大小写和空格，确认账号未停用；忘记密码找管理员，不连续尝试 |
| 没有账号管理菜单 | 成员角色的正常情况；请管理员操作 |
| 点预设后生成仍失败 | 预设只填表单，各卡片须分别保存；核对服务商、模型、Key 和余额 |
| 测试模型成功但生成失败 | 测试不会保存；先保存配置，再检查任务输入和服务商限制 |
| 链接提取失败 | 检查链接、厂商权限、预算、余额和平台限制；视频可改用人工输入文案 |
| 图文不能上传参考图 | 先核对当前是否 GLM；其仅支持文字生图，切换支持参考图的协议并保存 |
| 生成部分图片失败 | 保留成功结果，用继续／重试未完成图片，不反复重新提取整篇 |
| 授权暂时不可达 | 等待恢复，保留稿件；不要立即卸载或清空 Key |
| 已生成但历史保存失败 | 先复制或导出当前结果，查看日志与存储目录权限，再重试保存 |
| 迁移后资料不见 | 查看当前目录、下次启动提示和迁移错误，检查原目录备份，勿重复移动文件 |

临时授权连接故障会保留本地会话。新任务在通过授权前不会调用供应商；进行中的任务最多在最近一次成功授权后获得 60 秒宽限，超时停止，保留草稿和已保存图片。明确停用、密码重置或登录失效会取消本机任务并要求重新登录；供应商任务可能仍在执行。

### 9.3 提供排查信息

进入“设置 → 系统设置 → 打开运行日志”。提供软件版本、发生时间、操作步骤、完整错误文字和相关日志片段，必要时附脱敏截图。日志按日期和大小轮转，保留 14 天且最多 20 个文件，应及时留存问题时段。

发送给管理员前移除软件密码、供应商 Key、令牌和敏感业务资料；不要直接发送整个应用数据目录。

## 10 首次使用自查与版本依据

### 10.1 首次使用自查

1. 已安装 1.0.27，绑定地址来自管理员，能正常登录。
2. 所需接口卡片均已分别保存，测试成功后也已保存配置。
3. 公司背景、关键词和知识库正确，关键商业事实有依据。
4. 已完成一条视频脚本，或一套小红书图文，并核对原文与结果。
5. 生成结果已保存，能在历史找到，导出文件能正常打开。
6. 已了解正常升级、停用、重置密码、清空配置和主动卸载的区别。

### 10.2 核对依据

版本依据 package.json、release/latest.yml、release/universal-package-acceptance-1.0.27.json；操作依据 src/views 中的登录、设置、工作台、图文、历史与账号管理界面。安装行为核对 installer/authServerBinding.nsh 和 authServerBinding.ps1；功能限制核对 electron/services 中的接口、素材、存储与授权实现。

本文不把隔离验收等同于真实商业供应商全面联调。供应商模型、价格、权限和服务能力以实际账号为准。

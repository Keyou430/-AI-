# 通用 API 设置与 Seedream 接入

日期：2026-10-29。范围：当前源码及 1.0.18 安装包；旧 1.0.17 安装包不包含本次改动。

## 使用方式

系统设置包含“智能二创／内容提取／图片生成”三张卡片，独立保存与测试。每张卡片显示未配置、已配置或有未保存修改。快捷预设只填表，不保存、不发请求；地址和模型仍可修改。

| 模块 | 快捷配置 | 自定义范围 | 测试方式 |
| --- | --- | --- | --- |
| 智能二创 | DeepSeek | OpenAI 兼容对话接口地址、模型、Key | 使用当前表单发送短文本测试 |
| 内容提取 | LinkDigest、姚安 | 基础地址；原自定义请求方式、鉴权、字段映射、超时 | 使用当前表单与测试分享链接调用对应适配器 |
| 图片生成 | Agnes、Seedream | 两种兼容协议、完整地址、模型、Key | 生成一张正方形静物样图，仅作预览 |

模型预设以官方公开文档核对：DeepSeek 为 deepseek-flash，Seedream 为 doubao-seedream-5-0-pro-260628。模型可按账户可用标识修改。代码中的 Seedream 默认设置为 2K 明确像素尺寸，以保持原有八种整套比例；最多 10 张参考图，包含风格、本页素材及沿用上一版图片，重复素材去重。不自动重试生图，不自动下载 URL 格式返回；兼容服务须返回 data[0].b64_json。

## 保存与兼容

- 配置继续保存在本机 providers.encrypted，使用操作系统安全存储加密；界面仅返回地址、模型和密钥配置状态，不回显已保存密钥。
- 同一服务商 Key 留空保留原值；更换模型服务域名、提取厂商／域名、图片协议／域名时须提供新 Key。切换为明确无需密钥的自定义提取协议时清除旧提取 Key。
- 保存一张卡片不覆盖其他模块配置或输入。测试使用当前表单，允许在同一服务商复用已保存 Key，但不写回配置。
- 旧 Agnes 配置自动映射到通用图片字段；旧提取预设曾忽略残留地址，迁移时继续忽略，避免把旧厂商 Key 误发到残留地址。新保存的预设地址可编辑且真实用于请求。
- 图片测试不写业务历史；正式图文生成沿用确认一次、单页优化、仅重生成受影响页面、版本与历史保存、事实约束。鉴权、额度或限流错误停止后续页面，失败保留原图。

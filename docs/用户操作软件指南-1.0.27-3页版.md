# 用户操作软件指南

适用版本：视频二创 AI 助手 1.0.27
整理日期：2026年11月5日
适用人员：新媒体运营、内容创作人员、账号管理员

本软件把抖音、小红书视频素材整理为二创脚本，或把小红书图文整理为图片及发布文案；发布仍需人工完成。

## 1 安装与登录

1. 运行 1.0.27 安装包，选择安装位置。
2. 在“绑定授权服务器”填写管理员提供的 HTTPS 根地址（如 https://auth.example.com），不要加 /health、/v1 等路径。
3. 验证通过后完成安装；启动软件，用账号密码登录。

升级直接运行新安装包；换服务器需卸载重装（清除绑定和本机 API 配置，保留历史与素材）。忘记密码或账号停用联系管理员。

## 2 首次配置

在“设置 → 系统设置 → API 接口配置”分别配置并保存：

| 卡片 | 填写与保存 |
| --- | --- |
| 智能二创 | 点“使用 DeepSeek 配置”或填地址、模型、Key，测试后点“保存本设备接口配置”（预设 https://api.deepseek.com / deepseek-flash） |
| 内容提取 | 选服务商、填 Key 并保存；LinkDigest 单次积分上限默认 5，可设 1–1000 |
| 图片生成 | 选协议并保存：Agnes 支持参考图；Seedream 最多 10 张；GLM 仅文字生图（≤1000 字符，不支持参考图）；Sub2API 支持文字及参考图，最长 30 分钟 |

在“设置 → 内容设置”填产品、服务、受众和关键词（业务/卖点/禁用词），知识库导入 TXT/MD/PDF/DOCX/CSV/JSON，仅启用的文档参与创作。每张卡片分别保存，不要混填 Key。

## 3 视频脚本二创

在“二创工作台”：

1. 粘贴抖音/小红书分享链接，点“提取文案”。
2. 核对并修正“口播文案”“画面描述”。
3. 在“生成选项”设置时长 6–180 秒，可选“指定运镜”，点“生成二创脚本”。
4. 结果区查看“拍摄脚本”“拍摄手法”“口播稿”“全文”；点“优化脚本”修改，版本可回退。
5. 导出：历史记录 → 选中视频 → “导出”为 TXT 或 .doc（标准 DOCX 需另存）。

提取和生成是两步；无链接可直接输入文案。发布前人工核对事实、禁用词和镜头。

## 4 小红书图文二创

在“小红书图文”：

1. 粘贴图文链接，点“提取并继续”，等待策划草案。
2. 核对“文案”（标题、正文、话题）和“逐图”（图片内文字、画面要求）；可增删图，整套 1–30 张。
3. 在“风格”调整风格，在“素材”补充参考图。
4. 选比例（1:1、3:4、4:3、16:9、9:16、2:3、3:2、21:9），点“确认文案、张数及比例，开始生成 N 张图片”。
5. 失败点“继续／重试未完成图片”；单图优化改文字/画面，“全局优化”改整套。
6. 逐页勾选“图内文字已核对”，点“保存”，用“复制文案”取标题正文话题，“导出素材包”生成编号 PNG、发布文案.txt、内部核对.txt。

参考图支持 PNG/JPG/JPEG/WEBP，单张 ≤20 MB，稿件最多 30 个；GLM 不支持参考图。无成功图片的页面导出时会跳过。

## 5 历史与账号

1. 历史记录：按类型/平台筛选或搜索；视频可复制、导出、重新编辑，图文可重新编辑、复制发布文案、导出素材包。删除不可撤销，需保留先导出。
2. 存储：设置 → 系统设置 → 更改存储地址；迁移下次启动生效，原目录保留备份。
3. 账号管理（仅管理员）：填账号、姓名、初始密码、角色新增。账号 3–50 位，姓名 1–100 字，密码 8–128 位。停用会清该 Windows 用户的三类 API 配置；重置密码旧会话失效；删除不可撤销。内置 admin 和当前登录账号不能停用/删除。

## 6 常见问题与自查

| 问题 | 处理 |
| --- | --- |
| 安装验证失败 | 核对 HTTPS 根地址、网络和证书 |
| 授权绑定无效 | 保存资料后用 1.0.27 卸载重装（会清除 API 配置） |
| 密码正确仍无法登录 | 核对大小写/空格，确认未停用；忘记密码找管理员 |
| 预设/测试后生成失败 | 各卡片分别保存；核对服务商、模型、Key、余额 |
| 链接提取失败 | 检查链接、权限、预算、余额；可改人工输入 |
| 图文不能上传参考图 | 当前为 GLM；切换支持参考图的协议并保存 |
| 生成部分图片失败 | 保留成功结果，重试未完成图片 |
| 授权暂时不可达 | 保留稿件等待恢复；不要卸载或清空 Key |

首次自查：能登录；三类接口分别保存；知识库正确；跑通一条视频或一套图文；结果能在历史找到并导出。日志在“设置 → 系统设置 → 打开运行日志”，发送前移除密码、Key 和令牌。

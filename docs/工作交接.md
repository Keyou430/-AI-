## 四、注意事项与风险提示

1. **重启会影响全部登录。** 服务端会话在内存，重启会使现有会话失效，需重新登录；这与客户端临时网络故障保留会话是不同场景。账号重新启用也不会恢复旧会话。
2. **中断不等于退款。** 提取服务等待超时、退出或停权只中断本机等待，不承诺取消厂商任务；再次提取可能重复计费。网络恢复后需手动重试，原生成任务不会自动续传。
3. **本机数据需单独保护。** 同一电脑不同账号共享业务资料，账号删除不删除历史。更改存储目录需重启迁移并核对结果，原目录保留备份；设备密钥、日志和界面偏好不随业务数据库迁移。跨设备／系统用户复制加密配置不保证可解密。
4. **误触保护仍有待办。** 知识库直接删除、恢复原稿／重新填入、重新提取、加载历史可能影响未保存内容；停用账号会让多设备下线。建议按风险补确认或撤销，不能将这些建议视为已完成。普通二创会替换当前显示，但先前已保存历史仍保留。
5. **授权不等于内容与 Key 可收回。** 停用账号不能收回已导出的资料或已复制的供应商 Key；额度与撤销需在供应商侧管理。日志、截图和交接资料不要附带密码、Key、令牌或含敏感参数的完整链接。
6. **单实例与恢复。** 当前服务使用 sql.js，不支持多个服务实例同时写同一账号数据库；备份限制访问，并安排异地副本与恢复演练。HTTPS 证书续期需保持 Caddy 与相关网络配置正常。
7. **文档版本要区分。** 客户端以 PRD／README 的 1.0.13 为准，线上授权服务以 1.0.11 部署记录为准；部署文档开头仍写客户端 1.0.11，属于过时表述。TASKS 下半部分及旧安全报告为历史记录，不能套用旧版仿真模式或断网退出结论。

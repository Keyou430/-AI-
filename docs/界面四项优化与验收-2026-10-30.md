# 界面四项优化与验收

日期：2026-10-30。基线为当前已验收的 1.0.18 工作区，保留原有未提交改动。本轮完成源码修改与构建后桌面验收，未重新生成安装包。

## 完成内容与预期效果

| 需求 | 实现 | 已验证效果 |
| --- | --- | --- |
| 清空 API 配置并重新填写 | API 设置顶部增加清空入口，使用现有确认弹窗；清除本机加密配置及遗留临时文件，重建三张表单；配置读取失败时入口仍可用 | 正常配置、未保存输入和无法解密的配置均可清空；取消保留旧配置；清空后可重新保存密钥，不恢复旧密钥，不删除业务资料 |
| 图文右半区左图右文 | 图文与历史继续共用 ImageTextResult，统一为容器宽度达到 520 像素时左右展示；更窄时沿用上下布局 | 1280 像素窗口下，699 像素的结果容器也可左右展示；图片固定，文字独立滚动；翻页、图片优化与页面版本保留 |
| 每次进入历史默认最新 | 进入历史时重置旧选择、平台筛选与搜索；视频与图文按创建时间统一倒序，加载完成后选择最新记录并展示详情 | 最新内容为视频、图文两种情况均自动打开；重新进入不沿用旧选择；视频列表异步刷新不会覆盖图文选择；手动选择优先于尚未完成的默认选择 |
| 删除两项测试操作 | 移除内容提取、图片生成测试按钮及专用链接输入、样图预览；保留文本模型连接测试和独立保存 | 设置页无对应测试控件；快捷预设、清空与页面切换不自动触发提取或图片请求 |

清空范围为本设备的三个 API 模块；清除后图片字段可以显示内置预设，但旧服务商地址、模型与密钥不再从保存文件恢复。用户需要重新填写并保存所需接口。

## 改动范围

产品文件共 8 个：

- electron/services/localProviderService.ts：新增不依赖旧配置可解密的 reset。
- electron/main.ts、electron/preload.ts、src/services/ipcClient.ts：补齐配置重置 IPC，沿用现有登录与来源校验。
- src/components/ProviderSettingsForm.tsx：清空确认、错误恢复入口、表单重置，以及移除两类测试界面。
- src/components/imageText/ImageTextResult.tsx：统一两个页面的左右布局条件。
- src/store/useAppStore.ts、src/views/HistoryView.tsx：进入历史重置与跨内容类型的默认选择，避免加载覆盖人工选择。

回归用例补充在 tests/providerModules.test.ts、tests/frontend.test.ts；桌面验收适配在 scripts/providerSettingsSmoke.cjs。另两个已有桌面脚本仅调整本轮证据日期目录。未修改数据库结构、供应商协议、授权服务或 docs/工作交接.md。

# 链接提取与人工二创（1.0.5）

目标流程：粘贴链接 → 提取发布文案与视频口播 → 人工修改 → AI 二创 → 历史保存／导出。

## 配置与边界

- 使用同一通用安装包；服务器只鉴权。提取和模型请求从本机直接发给厂商。
- 设置页选择姚安 AIGC 并填一把提取 Key；另填一把 DeepSeek Key。“使用 DeepSeek 配置”填充 https://api.deepseek.com 与 deepseek-flash，允许手工调整。
- 密钥通过系统安全存储加密落盘；留空保留、填写新值覆盖。厂商切换须填新 Key；新设备为空。
- 聚合预设只处理发布正文与音频转写，不识别视频画面，不对多图笔记执行 OCR。未知时长显示未知，不伪造内容。
- 提取后原始正文和口播保留；编辑稿独立保存，二创以编辑稿为主。历史保存原始快照与实际模型输入；旧历史兼容读取。
- 每次点击提取只发一次请求，无自动重试。二创和优化只调用模型。重复提取可能重复计费。

## 已核对的公开协议（2026-10-22）

| 平台 | GET 路径 | 密钥查询字段 | 分享字段 |
| --- | --- | --- | --- |
| 抖音 | https://cyanlis.cn/api/plugins/douyin/dy_video_to_text | api_key | url |
| 小红书 | https://cyanlis.cn/api/plugins/xiaohongshu/video_to_text | apiKey | url |

两平台均指定 use_own_key=false，使用厂商内置识别。成功条件为 success=true、code=0；发布文案读取 data.desc，口播读取 data.audio_text，转写另检查 data.is_audio_success。抖音 data.duration 按文档从毫秒转秒；小红书未明确单位，不猜测。

- 401：更新 Key；403：检查余额／权限；429：限流／额度；其他失败提示手动检查。
- 转写失败、空口播、图文笔记分别提示；已取得正文与部分文字仍保留，可人工补充后生成。
- 厂商原始 msg 不向用户回显，避免包含凭据。日志不保存密钥或业务正文。

## 验收状态

自动化协议样本与隐藏桌面验收不调用商业接口，不代表实际供应商效果。真实联调仍需有效聚合 Key、DeepSeek Key，以及有权使用的抖音视频和小红书视频样本，逐项核对发布正文、口播准确度、编辑后二创和失败提示。未完成真实样本验收前，不宣称提取准确率或稳定性达标。

# 通用版账号服务部署

授权服务只处理账号、会话、权限和审计。知识库、素材、历史和 API 密钥保存在员工设备，模型及内容提取请求由客户端直接发送。

## 构建与配置

使用 Node.js 22.12 或更高版本，执行：

```powershell
npm ci
npm run build:auth
```

运行入口为 `dist-server/server/main.js`。服务配置以 [server/main.ts](../server/main.ts) 为准，反向代理和服务单元模板位于 [deploy](../deploy/)。模板中的域名、文档示例 IP 和目录均需按自己的环境调整。生产服务须使用可信 HTTPS，限制账号数据及初始化密码文件的访问权限。

初始化管理员通过运行环境配置；不要将密码、账号库、证书、私钥或实际部署信息提交到仓库。更新前先备份服务代码和数据，停止写入后再替换文件。服务重启后用户需要重新登录；同一 sql.js 数据库不得由多个服务实例同时写入。

## 客户端安装绑定

公开安装包不预置授权服务器地址，也不会读取构建环境中的地址。首次安装时由使用者填写自己的 HTTPS 根地址，安装器验证 `/health` 和未登录的 `/v1/me` 响应。

已有有效绑定的覆盖升级保留地址与本机 API 设置。旧固定地址版若尚未生成安装绑定，升级时需要填写地址；无绑定时拒绝静默安装。绑定缺失或损坏时拒绝启动，不回退至默认服务器。

主动卸载会清除绑定和本机 API 设置，保留数据库、素材与业务资料。需要更换地址时卸载重装，并重新填写接口密钥。断网或停服不会解除绑定。

## 验证

- `npm run typecheck`：前端、Electron 和授权服务类型检查。
- `npm test`：源码测试，含绑定读取、配置生成和安装 PowerShell 协议样本。
- `node scripts/authInstallerSmoke.cjs`：使用临时目录验证 NSIS 静默拒绝、覆盖升级、卸载清理及业务资料保留。

部署地址、生产账号、压测结果、运行日志和恢复备份仅保存在仓库外。

# 历史记录删除确认与误触排查

日期：2026-10-27。

本次实施范围：历史记录删除确认、删除失败反馈及回归验收。其他交互仅做代码排查和建议，未修改其业务行为。排查依据为当前源码；系统原生对话框的行为如未实测，单独注明。

## 已完成的历史记录删除保护

- 位置：`../src/views/HistoryView.tsx`。列表删除入口只打开居中确认窗口，展示记录标题、永久删除范围和不可撤销提示；确认后才调用原删除接口。
- 默认聚焦“取消”；取消、关闭和 Escape 均不提交删除。
- 请求期间按钮禁用、窗口不可关闭，并通过同步锁防止快速重复提交。
- 删除失败保留窗口和记录，窗口内及顶部 Toast 显示具体原因，允许重试。
- `../src/services/ipcClient.ts` 对主进程返回的失败结果抛出错误，避免把失败当作完成；未改变数据库删除范围。

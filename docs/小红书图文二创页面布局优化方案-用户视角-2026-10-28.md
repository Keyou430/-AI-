# 小红书图文二创页面布局优化方案（用户视角）

- 日期：2026-10-28
- 范围：只讨论"小红书图文二创"主页面的布局与收起方式，不改生成逻辑，不加新功能。
- 依据：当前工作区源码（`src/views/ImageTextView.tsx` 及 `src/components/imageText/`），并对照视频工作台、脚本结果、设置页的现有样式。安装包本身没有打开核对，前提是安装包由当前代码构建。

## 一、谁在用，怎么用

使用者是新媒体运营，每天处理若干篇小红书图文二创。一次完整操作通常是：

1. 粘贴小红书分享链接，点"提取并继续"。
2. 等系统自动策划出标题、正文、话题和每张图的内容。
3. 核对文案，逐张检查图内文字和画面要求，必要时增删、拆分、调整顺序。
4. 选好整套比例，点一次"确认"，系统连续生成全部图片。
5. 逐张看图，不满意的用"图片优化"重做；核对图内文字后打勾。
6. 复制发布文案，导出素材包。

用户最常做的是第 3 步和第 5 步，最在意的是"改得快、找得到按钮、不漏看问题"。

## 二、用户现在遇到的问题

按操作顺序列出，都是在同一个窗口里能直接感受到的：

1. **提取完不知道先看哪里。** 第一屏依次是原帖素材入口、系统提示、知识库说明、自查结果，真正要改的标题和正文要往下找。
2. **确认按钮在最底部。** 左栏把文案、风格卡、比例、上传按钮、素材列表、当前图编辑、结构按钮全部排成一列，"确认并开始生成"要滚到页面最下面才看得到。
3. **改第 N 张图要来回滚。** 切换第几张图的控件在右栏顶部，编辑这张图的输入框在左栏中下部。翻一张图、改一处，要上下滚动一次。
4. **同样的文字出现两遍。** 左栏能改当前图文字，右栏图片下面又显示一遍；标题、正文、话题也在右栏底部重复。用户分不清哪一处能改、哪一处是结果。
5. **不常改的内容一直占位置。** 整套风格卡有 5 个多行输入框，大多数时候不需要动，却始终展开。
6. **素材一多，页面更长。** 参考素材最多 30 张，列表直接铺在编辑区中间，把下面的逐图编辑挤得更远。
7. **进度和报错会被滚走。** 生成过程中的进度、取消按钮和报错都在页面顶部，用户滚到下面看图时就看不到了。
8. **看起来和视频工作台不像一个产品。** 折叠块的边框、字号和视频工作台的"原始素材""画面描述"不一样，分页切换方式也不同。

## 三、用户每一步真正需要什么

判断标准只有一条：**这一步不看它就没法往下走的，是核心；出了问题才去看、只有部分人用、改一次就不再动的，是非核心。**

| 阶段 | 用户此刻要做的事 | 必须一眼看到（核心） | 偶尔才看（非核心） |
|---|---|---|---|
| 提取后、确认前 | 核对文案和每张图，定比例，点确认 | 标题、正文、话题；当前图文字和画面；张数和比例；确认按钮；图片预览和翻页 | 原帖原文、提取说明、知识库说明、自查结果、风格卡、参考图、结构调整按钮 |
| 生成中 | 等待，必要时取消 | 进度、取消按钮、报错 | 其余全部 |
| 生成后、检查图片 | 逐张看图，优化，打勾核对 | 图片预览和翻页、图片优化、版本切换、"已核对"勾选、继续或重试未完成图片 | 本图文字与画面要求、风格摘要、参考图 |
| 发布前 | 复制文案，导出素材包 | 顶部的保存、复制文案、导出素材包 | 发布文案全文（复制前想再看一眼时） |

## 四、收起哪些内容

| 内容 | 用户什么时候会用 | 收起后去哪找 | 收起时仍能看到 |
|---|---|---|---|
| 原帖原文与提取说明 | 想对照原帖时 | 左栏"核对"页，折叠块"原帖素材" | 折叠块标题 |
| 知识库使用说明 | 第一次用或拿不准时 | 左栏"核对"页，缩成一行 | 一行说明 |
| 系统提示（提取或策划时给的提醒） | 有提醒时 | 只有 1 条：在左栏标题下显示一行；多条：显示第 1 条，其余收进"还有 N 条提示" | 第 1 条提示和剩余条数 |
| 依据核对与图文自查 | 确认前检查一遍 | 左栏"核对"页 | 分页标签写"核对 · 2"表示 2 项提醒；有提醒时折叠块自动展开 |
| 整套风格卡（5 项） | 想改风格时 | 左栏"风格"页 | 一行风格摘要，例如"奶油色 · 大字标题 · 温暖" |
| 比例来源说明 | 想知道比例怎么来的 | 比例选择框旁边一行小字 | 小字本身 |
| 参考图上传按钮、说明和列表 | 需要补原帖图或场景图时 | 左栏"素材"页 | 分页标签写"素材 3"；说明压缩成一句 |
| 复制、拆分、合并、上移、下移 | 调整图片顺序或张数时 | 左栏"逐图"页的折叠块"调整分页结构" | 折叠块标题；"增加一图""删除当前图"留在外面 |
| 重新策划草案 | 对整份草案不满意时 | 左栏底栏，作为不醒目的次要按钮 | 按钮本身，和主按钮拉开距离，避免误点 |
| 右栏图片下方的本图文字和画面 | 确认后想对照图内文字时 | 确认前去掉（左栏已能编辑）；确认后收成"本图文字与画面要求" | 折叠块标题 |
| 右栏底部的标题、正文、话题 | 发布前想再看一眼 | 确认后放到左栏"发布文案"页 | 分页标签 |

## 五、分页和收起怎么用

### 分页（左栏）

- 左栏顶部是一排分页标签，点一下切换。长相和选中效果与脚本结果的"分镜 / 技巧 / 口播……"、设置页的"内容设置 / 系统设置"相同。
- 确认前的分页：**文案｜逐图｜风格｜素材 N｜核对 · N**。确认后的分页：**概览｜发布文案｜素材 N｜核对 · N**。
- 标签上直接写数量，不用点进去也知道有几张素材、几项提醒。
- 新提取的草稿默认停在"文案"；点确认后自动切到"概览"。
- 切换分页不会丢掉刚输入、还没离开输入框的内容。
- 生成过程中可以切换分页浏览，输入框照常锁定。

### 和右侧翻图的配合

- 左栏停在"逐图"页时，右侧翻到第几张，左侧就显示第几张的文字和画面，两边同屏，不用滚动。
- 左栏停在其他分页时，右侧翻图不会把左栏强行切走，免得正在改正文时被打断。此时"逐图"标签显示为"逐图 · 第 3 图"，提醒用户当前是哪一张。

### 收起（折叠块）

- 点折叠块标题展开或收起，样式和视频工作台的"原始素材""画面描述"一致。
- 标题上写清楚里面是什么，例如"原帖素材""调整分页结构""还有 2 条提示"。
- 里面有问题或已有内容时自动展开：自查有提醒、图片有报错、"本图文字与画面要求"在用户改过之后。

### 窄窗口

- 窗口较窄时只显示一栏，顶部出现"策划编辑 / 图片预览"两个切换按钮，用法和视频工作台的"素材编辑 / 生成结果"一样。
- 生成中，"图片预览"按钮上显示转圈图标，用户在编辑页也知道正在生成。

## 六、调整后用户看到的页面

整页高度等于窗口高度。大窗口下整页不再滚动，左右两栏各自在栏内滚动。

### 确认前

```
顶栏（固定）
  小红书图文二创                         保存 ｜ 复制文案 ｜ 导出素材包
  [ 粘贴小红书分享链接…… ]  粘贴  提取并继续
  （进度、取消任务、报错固定显示在这里，不随内容滚走）

左栏：编辑
  核对并确认               自动识别 · 6 张 · 重新策划草案
  文案 ｜ 逐图 ｜ 风格 ｜ 素材 2 ｜ 核对 · 1
  ……当前分页的内容（只在本栏内滚动）……
  底栏（固定）
    共 6 张 · 整套比例 [3:4]（来源见悬停提示与读屏说明）
    [ 确认文案、张数及比例，开始生成 6 张图片 ]

右栏：预览
  整套比例 3:4 · 尚未生成
  图片预览区（该页文字、比例来源与确认说明）
  ‹ 上一图     第 2 / 6 图     下一图 ›
```

### 确认后

```
左栏：编辑
  稿件与素材
  概览 ｜ 发布文案 ｜ 素材 2 ｜ 核对 · 1
  概览页：整套比例与风格摘要、操作说明、[ 继续／重试 2 张未完成图片 ]

右栏：预览
  整套比例 3:4 · 已生成                    图片优化
  图片预览区
  ‹ 上一图     第 2 / 6 图     下一图 ›
  页面版本 [ 3 · 10/28 14:20 …… ]     □ 图内文字已核对
  本页报错（如有）
  ▸ 本图文字与画面要求
```

### 用户的操作顺序

1. 在顶栏粘贴链接，点"提取并继续"。
2. 左栏停在"文案"页，改标题、正文、话题。
3. 切到"逐图"页，右侧逐张翻图，左侧同屏修改图内文字和画面要求；需要增删或调整顺序时展开"调整分页结构"。
4. （可选）到"风格"页改风格，到"素材"页补传参考图。
5. 看一眼"核对"标签有没有数字，有就点进去处理。
6. 在左栏底栏选比例，点"确认……开始生成"。
7. 生成中，进度一直在顶栏，可随时取消。
8. 生成后在右栏逐张看图：不满意点"图片优化"，满意就勾"已核对"，需要时切换版本。
9. 在顶栏复制文案、导出素材包。

## 七、和其他模块保持一致

目标是用户从视频工作台切过来，不用重新学怎么用：

- **左编辑、右结果。** 和视频工作台的"素材 / 脚本结果"同一种两栏结构，主按钮都固定在左栏底部。用户在视频工作台习惯了去左下角点"生成二创脚本"，到这里同样去左下角点"确认并开始生成"。
- **分页长相相同。** 分页标签的大小、间距、选中底色与脚本结果、设置页一致。
- **折叠块长相相同。** 边框、字号、标题粗细与视频工作台的"原始素材""画面描述"一致，不再出现样式不同的折叠入口。
- **提示和报错长相相同。** 灰底提示条、红色报错与视频工作台一致，位置都在顶栏下方。
- **按钮层级相同。** 每个面板只有一个醒目的主按钮，其余是普通按钮或文字按钮；删除类操作用红色。
- **窄窗口切换方式相同。** 都用顶部两个切换按钮。
- 不新增颜色、图标风格和交互方式。

## 八、调整前后对比

| 场景 | 现在 | 调整后 |
|---|---|---|
| 找确认按钮 | 滚到页面最底部 | 一直在左栏底部 |
| 改第 N 张图 | 右边翻图，左边往下找输入框 | 左栏"逐图"页，和右侧翻图同屏 |
| 看系统提醒 | 混在长页面中间 | "核对"标签显示数量，有提醒自动展开 |
| 上传多张参考图 | 列表把编辑区往下挤 | 只出现在"素材"页 |
| 生成中看进度 | 滚下去就看不到 | 固定在顶栏 |
| 分辨哪里能改 | 同样的文字出现两遍 | 左栏改，右栏看图，不重复 |
| 一屏内容量 | 十几块内容排成一列 | 每个分页一般 3 到 5 项 |
| 翻页条与图片距离 | 翻页在右栏顶部，与图片隔着状态行 | 紧贴图片框下方；状态与图片优化留在栏头 |

## 九、验收标准（站在用户角度）

1. 在 1366×768 和 1920×1080 窗口下，确认前不滚动整页就能同时看到确认按钮和图片预览。
2. 逐张核对 6 张图的过程中，不需要上下滚动整页去找翻图控件或输入框。
3. 每个收起的内容，从标题就能看出里面是什么、有没有问题。
4. 自查有提醒、图片有报错时，用户不点开任何东西也能注意到。
5. 切换分页、翻图之后，已输入的内容不丢失。
6. 用过视频工作台的用户，第一次打开图文模块就能找到主按钮、分页和折叠内容。

- 文案策划、生图、导出的逻辑和规则。
- 新增功能或新增设置项。

### 11.4 分页定义与状态

在 `ImageTextView.tsx` 内定义：

```ts
const planTabs = ['copy', 'pages', 'style', 'assets', 'review'] as const;      // 确认前
const confirmedTabs = ['overview', 'publish', 'assets', 'review'] as const;   // 确认后
type ImageTextTab = (typeof planTabs)[number] | (typeof confirmedTabs)[number];
```

| 值 | 标签文字 | 内容（来自现有代码，只搬位置） |
|---|---|---|
| `copy` | 文案 | `发布标题`、`配套发布正文`、`TagsField` |
| `pages` | 逐图（不在本页时显示"逐图 · 第 N 图"） | 当前图标题行、`图片内文字`、`画面要求`；增加一图、删除当前图；`details.disclosure`"调整分页结构"包住复制/拆分/合并/上移/下移 |
| `style` | 风格 | `ImageTextStyleCardEditor` |
| `assets` | 素材 N（N = `draft.references.length`） | 两个上传按钮、一句说明、`ImageTextReferences` |

### 11.8 风险与注意事项

- **隐藏分页里的提醒可能被忽略。** 分页标签必须显示数量；错误类信息（`state.error`、`page.error`）不能只放在隐藏分页里。
- **`keepMounted` 的副作用。** 隐藏分页仍在 DOM 中，`textContent` 能读到、`innerText` 读不到，写测试时注意区分。参考素材预览图在隐藏分页里也会加载，素材较多时留意内存占用。
- **确认后分页列表变化。** 当前分页值可能失效，必须按 11.4 的回退规则处理，否则 `Tabs` 会没有选中项。
- **生成中切换分页。** 输入框照常按 `busy || uploading` 禁用，不新增其他限制。
- **弹窗不受影响。** `Modal` 内的字段、按钮文字、`ImageTextReferences` 用法都不改，现有弹窗相关断言应当照常通过。
- **回滚。** 改动只在渲染层和测试脚本，不涉及数据和接口，回滚时撤销相关提交即可。

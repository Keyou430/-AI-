## 实施时固定的规则

1. 归属标识拟由稳定的授权体系标识与不可变 userId 共同生成。授权服务换域名或迁址不改变其体系标识；切换到另一套授权服务不沿用原空间。本机身份随对应账号数据库保存。当前没有这套持久化体系标识，须新增，不能仅对 URL、用户名或文件路径做哈希。
2. 拟新增的 owner_scope_id 由主进程填写。业务读取没有“省略范围即查询全部”的默认值。远程账号不一定存在于桌面的 users 表，不能直接将业务归属外键指向桌面 users.id；应独立建模授权体系与业务空间。
3. 旧记录、知识库、素材、公共前端存储及设备 API 配置在归属确认前全部待分配，普通账号不可见；不自动分配给首个登录者，也不作为管理员个人空间的数据。归属分配是独立管理操作，需清单、预览、审计及幂等执行记录。
4. 旧 API 配置不复制给全部账号。新账号缺配置时要求该账号填写；确认归属后才允许单独迁移旧配置。配置读写核对密文归属；清理配置不依赖旧配置能否成功解密。
5. 既有全局记录 ID 可保留，但保存冲突必须在同一事务内拒绝其他账号的 ID，不能只在更新语句外查询一次，也不能继续让 REPLACE 删除对方行。稿件和版本的保存、删除使用相同归属。索引根据最终查询建立，避免无必要的重复索引。
6. 账号目录名由主进程根据规范化范围计算；UI 不提交可信文件路径或当前归属。输入图片、生成图片、受管理的导入副本、临时文件与导出暂存均放入对应空间。素材和清理队列的归属不明时，不推测删除目录。
7. 每次异步操作固定 scopeId、userId、sessionId/epoch、senderId 和取消信号（名称为拟定）。回传、流式分片、数据库提交、文件提交及错误提示均核对原上下文。身份查询仍沿用现有网络异常和任务宽限规则，不能用缓存身份放行新任务，也不对每个流式字符新增一次网络认证。
8. 历史记录导出由主进程按当前范围读取指定记录；工作台未保存内容的导出保留现有能力，但必须绑定发起会话。用户已经手动导出的文件不纳入软件账号目录的自动清理。
9. 业务恢复与后台维护分开：普通 IPC 没有跨账号查询入口；启动清理仅处理已经持久化、归属明确的清理任务，逐空间校验，不能复用前端传入范围或把旧无归属队列当成全局删除授权。

## 远程清理协议的必要补充（待实现）

拟新增的协议能力包括稳定 authorityId、协议/客户端兼容信息、单调增加的配置清理版本、必要的删除账号标记以及设备完成回执；这些字段和能力当前均未实现。

- 停用立即撤销访问；配置删除另记“待清理、成功、失败”。本机清理失败也不能恢复访问权限。
- 普通断网、超时、令牌到期、服务重启和重置密码不产生 API 清理指令。
- 当前撤销令牌后直接丢失服务端会话关联。新增协议需要让客户端取得与原身份绑定、可验证的清理信息；不能只向现有 401 响应随意附加前端传入的 userId，也不能仅凭 ACCOUNT_DISABLED 字符串删文件。
- 登录响应先核对授权体系和服务端清理版本，完成旧配置删除后才开放业务入口。重新启用后仍须清理错过通知的旧配置；已经完成的清理可重复执行而不影响其他空间。
- 删除账号保留必要的清理标记；删除账号、清配置和删除业务成果分开执行。回执丢失可重试，未回执的离线设备保持待处理。
- 清理操作与同账号配置写入、后台任务和备份恢复协同，防止旧任务在清理后重新写回旧密钥。新配置保存时带当前清理版本。
- 服务升级先于客户端；不支持所需能力的服务给出明确升级提示。对旧客户端的版本准入属于兼容机制，不替代资源归属校验，也不构成对直接读取磁盘的防护。

Electron 官方 Security 的 IPC 来源校验要求及 safeStorage 对 Windows/DPAPI 保护边界的说明，与本方案的应用内隔离边界一致；现有来源校验和安全存储继续保留。

## 必须新增的验收场景

- A、B、管理员使用不同配置和业务内容；列表、搜索、计数、知识核验、逐条读取、修改、删除、导出均只使用自己的空间。
- 绕过 UI 直接调用 IPC，伪造记录 ID、页面/版本 ID、素材 ID、owner 字段、跨空间引用、路径及目录链接；全部拒绝且错误不泄露对方内容。
- A 发起提取、模型流、图文策划、生图、连接测试、知识库导入、参考图导入、脚本/素材包导出后切换 B；A 的迟到结果、错误、文件和保存操作不进入 B。
- 同账号退出重登、未完成列表/配置加载后切换、持久化恢复晚于切换、图片预览晚于切换，不恢复旧会话状态。
- API 重置和停用清理 A，不影响 B，不删除 A 的历史、知识库和业务成果；无可信清理指令的网络故障不删配置。
- 原生 SQLite 和 WASM 均覆盖旧库升级、重复迁移、异常回滚、所有写入的归属约束及中断清理恢复。
- 业务根目录迁移与独立素材根目录迁移均覆盖多账号子目录、冲突、符号链接、磁盘不可达与部分失败。
- 回归现有 providerModules、imageTextPersistence、imageTextWorkflow、remoteAuth、remoteAuthNetwork、frontend、storageLocation、imageAssetLocation 等测试及桌面验收。前一轮脚本解析修复的通过结果不能当作本方案已验证。

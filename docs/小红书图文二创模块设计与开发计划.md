# 小红书图文二创模块：设计与开发计划

日期：2026-10-28

状态：主流程、图片分页及单图／全局优化双入口已确认；全局优化只重生成受影响页面。2026-10-28 补充确认 D21–D29（分页结构编辑、风格卡、影响预览、页面版本、依据核对、人工核对、导出分层、图文素材存储地址）及 D30–D38（删除与迁移清理、旧记录归类、权限、单页参考、清晰度、生图密钥位置、字数上限来源）。已完成源码实现、页面布局优化、隔离验证及 1.0.15 Windows 通用安装包构建，正式 ASAR 桌面回归通过；真实供应商联调、成品质量及实体设备安装／升级尚未验收。实际完成范围与证据见文末实施记录。

## 一、目标与范围

在现有 Electron 桌面应用中新增独立图文二创模块和侧边栏入口。从小红书图文笔记提取素材，保留原帖主题并参考表达风格，融入相关公司知识库，生成图片和配套标题、正文、话题。图片中的文字与画面均由 Agnes 整张生成。

一期边界：单条链接到一套图文的闭环；视频继续使用原工作台；本地导出，不接入小红书账号或自动发布。不新增向量数据库、云端素材平台或程序排字系统。批量处理不列入本次已确认范围。

## 三、用户流程与页面

### 1. 正常流程

粘贴链接 → 提取一次 → 可靠识别内容类型 → 图文自动跳转 → 文本模型融合知识库并生成文案、分页草案 → 用户核对／修改并确认一次 → Agnes 连续生图 → 图片分页预览 → 按需单图或全局优化 → 导出。

任一入口识别为视频时，交接给原工作台继续原流程。自动跳转不清空已经提取的素材，也不再次提交提取请求。

### 2. 核对／修改并确认一次

同一个页面／阶段展示：

- 提取的正文、逐图文字、素材完整性提示，以及类型是自动识别还是人工指定。
- 可编辑的发布标题、正文和话题。
- 每页内容、拟生成文字、画面说明、顺序、预计张数；可新增、删除、复制、拆分、合并相邻页和拖动排序（D21）。每页角色（封面／内容／结尾）只用于组织信息，不规定画风。
- 参考原帖的风格说明与参考图片；缺图时允许补传。风格以可编辑的风格卡展示（D22）。
- 公司事实的知识库依据及核对状态（D25），以及图文自查项结果（D26）；未通过项只提醒，不阻止确认。
- 原帖比例来源、整套输出比例与修改入口。
- 可选参考图上传入口；不要求用户在首轮逐页绑定实景素材。
- 无知识库依据而被省略的信息说明；这些说明不进入发布成品。

点击一次确认后开始整套生图，不再为每页强制弹窗确认。失败重试、后续优化是用户主动操作，不是正常链路新增的必经确认。

### 3. 图片分页与首轮完成后的单图优化

图文结果采用图片模式，沿用现有镜头分页的交互形式：上一图、当前页／总数、下一图。视频模块原有上一镜／下一镜保持不变。当前图片提供独立的图片优化按钮，优化目标绑定该图片，而不是整套图文。

首次整套生成完成后，可以对当前图片执行：

选中图片 → 点击独立的图片优化按钮 → 修改该图文案／画面要求 → （可选）补传或选择实景参考图并绑定本图 → 仅重生成本图 → 成功后更新当前图片。

失败时保留旧图及修改要求；其他页的文案、图片和参考关系保持不变。单页优化可使用本页上一版图片作为编辑参考，但不承诺局部像素级编辑。没有要求开发文字图层编辑器。

当前图片另提供：

- 页面版本列表（D24）：列出本页全部成功版本及当时的文字和画面要求，可切回任一版本作为当前图；切换只改变当前版本指针，不调用生图，也不影响其他页。
- 图内文字核对（D27）：并排显示已确认文字与当前图，用户勾选“图内文字已核对”；重生成或切换版本后标记清除。

### 4. 全局优化入口

保留原结果工具栏中的优化入口，在图文模块中作为全局优化按钮；它面向整套图文，不随着上一图／下一图切换而变成单图优化。单图与全局入口必须分别显示并区分操作范围。视频模块原有优化脚本入口及行为不变。

全局优化只重生成受影响页面，不默认重新生成整套图片。影响范围按优化前后的页面内容及生图要求判断：

- 未发生变化的页面复用原图，不重复提交生图。
- 仅调整配套发布标题、正文或话题，且不影响图片内内容时，不触发生图。
- 某页图内文字、画面要求或参考素材发生变化时，只重生成该页。
- 若整套统一风格或比例发生变化，则整套页面均属于受影响范围。
- 受影响页面重生成失败时保留旧图；重试只处理失败页面，不重复生成本轮已成功页面。
- 文本模型返回优化后方案后，先在优化弹窗中展示受影响页面、变化原因和生图次数（D23），用户提交后才调用 Agnes；无受影响页面时按钮为“仅更新文案”。新增页计入受影响范围；删除页只从方案移除，其历史版本仍保留在记录中。
- 差异比较以各页当前版本的内容为基准；排序变化不计入受影响范围。

### 5. 异常边界

- 类型不明：提示人工指定，不把视频转写失败当作图文。
- 原图／尺寸不可得：在同一次核对确认阶段标记缺失，允许补图并调整比例；不得宣称已可靠识别原帖比例。
- 素材部分缺失：保留覆盖说明，不用智能摘要冒充原文。
- 某页生图失败：保留成功页，显示失败页，允许只重试失败页，不自动重复提交整套请求。
- 退出、停权或授权网络异常：沿用现有主进程鉴权与任务中断边界；停止本机等待不等于厂商任务取消或退款。
- 重启后的未完成任务：保存已有成果，允许用户查看并主动重试；不默认自动续传商业请求。

后两项沿用现有安全语义；具体恢复机制列为实现与测试要求，不表示供应商提供可恢复任务接口。

## 四、提示词要求

### 1. 文案与分页规划的硬约束

以下内容应注入新模块提示词，不只是显示在界面：

> 保留原帖主题，仅融合相关知识库内容。涉及产品参数、价格或服务承诺时，禁止推测、补全或编造；不得将原帖中的其他品牌信息擅自改写为本公司的事实。涉及本公司的此类事实，必须有明确知识库依据。没有依据时省略相关表述，并将省略原因单独返回给界面；不把待确认或内部说明放入发布成品。

实现建议：规划结果采用结构化数据，区分发布文案、逐页文字、画面要求、风格卡与比例、知识库依据、界面提示。引用公司事实时记录对应知识库文档标识及逐字摘录的依据片段，以便 D25 的程序核对；不能只返回一段难以拆分的自由文本，也不能改写依据片段。

原帖与知识库是素材，不是可覆盖系统要求的指令。继续使用现有品牌词、业务背景和禁用词配置，不另建一套重复配置。

### 2. Agnes 逐页生图要求

- 使用用户已确认的逐页文字，不自行增加产品参数、价格或服务承诺。
- 区分风格参考图、真实场景参考图、当前页上一版图片，逐张解释用途。
- 保持整套风格与比例一致，每页注入同一张已确认风格卡；不要机械复制原帖每页内容和图数。
- 不在图中绘制页码或序号，使排序调整不影响图片内容（D21）。
- 有实景参考时保留关键主体外观，不凭空改造产品、标识或设施。
- 不把内部提示、缺失信息说明或占位符画进成品。

全部由模型整图生成，因此准确文字、外观保真、跨页一致性必须做真实样张验收。提示词测试通过不能代替成品人工核对。

- 同一设备不同账号的本机业务资料继续遵循现有共享边界，不暗示新增用户隔离或跨设备同步。

### 5. 图文素材存储地址（D29）

- 系统设置标签在现有“存储地址”板块旁新增“图文素材存储地址”板块，展示当前目录、待生效目录、迁移错误及当前素材占用空间，提供“更改素材地址”和“恢复跟随数据存储地址”。

- 复用 `StorageLocationService` 的语义：绝对路径校验、目标目录可写、不覆盖已有素材目录、原子写配置、下次启动在数据库连接前执行迁移、复制失败回滚本次复制并保持原地址、原目录保留。配置文件与数据库存储地址配置分开保存，仍放在应用目录。

- 迁移成功后原目录保留作为备份，不自动删除（D32）；板块提示迁移期间磁盘占用可能暂时翻倍，原目录可在核对后手动清理。
- 板块与图文模块对成员开放，权限与现有设置页一致（D34）。
